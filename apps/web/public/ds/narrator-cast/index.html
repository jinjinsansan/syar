切り替えの規則
パドック〜ゲート = D ／ 発走前のレース紹介 = C ／ 発走〜3コーナー = A ／ 最後の直線 = A（残り200mで表情「熱」→ゴール前100mで「絶叫」）／ゴール直後の一言 = B ／ 着順確定の締め = C。
入れ替えはクロスフェードなし。カット替えと同じ 3 フレームのフラッシュで差し替える。同時に 2 名は出さない。
⚠ 表情差分が上がるまでは「通常」の2枚だけで運用する（無い絵をあることにしない）。
⚠ 口パクは 6fps 固定。発話が終わったら必ず「閉」で止める。
