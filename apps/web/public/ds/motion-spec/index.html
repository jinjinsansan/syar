1. コマ送りは時間ではなく距離で回す
同じ 8 コマを一定 fps で回すと、減速しても脚だけ同じ速さで動き「氷の上」に見える。歩幅（1 完歩の距離）を決めて、進んだ距離からコマを引く。
STRIDE_M = 7.0 // サラブレッドの1完歩 ≒ 7m（襲歩） FRAMES = sheet.frames // 8（真横・後方・引き）／4（斜め3方向） phase(h) = (h.meters / STRIDE_M + gatePhase(h.gate)) mod 1 frame(h) = floor(phase(h) * FRAMES) mod FRAMES gatePhase(gate) = ((gate * 0.37) mod 1) // 全頭が同時に同じ脚を出さないための位相ずれ
目安: 16 m/s（レース速度）÷ 7 m = 2.3 完歩/秒 = 18.3 コマ/秒。60fps では約 3.3 フレームに 1 コマ。ゴール前の追い比べで 2.6 完歩/秒、道中で 2.1 完歩/秒。
⚠ frame を displaySec から作らないこと。カメラが寄っても引いても、コマ送りは距離だけで決まる。
