# 斜め俯瞰 — ★投影の約束（試作 ① 用）

**裁定**: レビュー側が **β（斜め俯瞰）** を採用。手順は
**①1頭だけ試作 → ②内/外・コーナー・ゲートが表示できることと V-16 を確認 → ③正典 §12.1 を改訂**

> ★**この文書は「絵を発注する前に、絵が置かれる場所を決める」ためのものです。**
> 第1便では**絵が先にでき、あとから構図を合わせた**ため、
> 「スプライト220px 対 房92px」のような**幾何の破綻**が最後まで残りました。

## 0. ★なぜ真横をやめるのか（裁定より）

|  | 真横 | 斜め俯瞰 |
|---|---|---|
| **内/外（D-065）** | ★**不可能** | 可 |
| **コーナー** | ★**不可能** | 可 |

| **カメラの自由度** | 寄る/引くのみ | ★**視点を変えられる** |

★**「表示できない次元を、結果に効かせろ」と決めていた**（D-065 × §12.1）というのが、
今回いちばん大きい発見です。**絵の問題ではなく、投影の問題でした。**

## 1. ★カメラ

```
                    （画面の上 = 内ラチ側 = 奥）
        内ラチ ────────────────────────────────────
                  ○ 内を通る馬（画面の上・小さい）
                        ○
                              ○ 外を回る馬（画面の下・大きい）
        外ラチ ────────────────────────────────────
                    （画面の下 = 外ラチ側 = 手前）

        馬の進行 → 画面の右
```

| 項目 | 値 | なぜ |
|---|---|---|
| **位置** | 走路の**外側・上空** | 内/外が画面の y に出る |
| **俯角** | ★**約 30°** | ⚠️ **真上（90°）にしない。** 馬が馬に見えなくなる（裁定より）。30° なら馬体の側面が主で、背も少し見える |
| **馬の向き** | ★**画面の右へ。やや向こう向き（¾ 後方・外側から見る）** | 勝負服の**背中**が見える＝18頭でも識別が速い（アートバイブル P-3） |
| **進行** | 画面の **x** | |
| **内/外** | 画面の **y**（上が内） | ★**これが D-065 の次元** |

## 2. ★縮尺（先に決める）

**走路の幅は 25m とします**（JRA の芝コースの幅はおおむね 20〜30m）。

| 量 | 画面 | 根拠 |
|---|---|---|
| 走路の幅 25m | ★**y 方向に 190 px** | 3〜4列の馬が重ならずに並ぶ最小 |
| 内外 1m | **7.6 px** | 上記より |
| 進行方向 1m | ★**26 px**（基準の画角） | 1馬身 = 2.4m = **62px** |
| **馬1頭の画面上の幅** | ★**110 px** | ⚠️ **馬体は 2.4m なので、実寸なら 62px。1.8倍まで**に抑える（真横では 4.6倍だった） |
| 奥（内）と手前（外）の大きさの差 | ★**なし**（同じ倍率） | D-058。奥行きは**接地線の y と重なり順**で作る。★非整数倍の縮小はしない |

★**真横のときの「絵が実寸の 4.6倍」を 1.8倍まで下げます。**
これで **12頭が重ならずに並べます**（12頭 × 110px を 25m 幅の中に散らせる）。

⚠️ **馬が小さくなります。** ★**それでも「何頭いるか・誰が前か」が読めることのほうが先**です
（オーナー判定「大小わけのわからない状態」「追い抜き方が不自然」は、重なりが原因でした）。

## 3. ★スプライトの契約

| 項目 | 値 |
|---|---|
| **1コマの寸法** | ★**128 × 96 px** |
| **馬体の幅** | 110 px 前後（鼻先〜臀端。★尾を含めない） |
| **接地点** | ★**セルの下端。横は中央ではない**（下記） |
| **表示倍率** | ★**1× と 2× のみ**（D-058） |
| **コマ数** | ★**試作は 1コマ**。動きの検証は②で |
| **背景** | 完全透明（アルファ 0 か 255 のみ） |
| **勝負服** | ★**青系（色相 200〜260・彩度 0.35 以上）の一続きの塊**。あとで枠順色に置換 |
| **ゼッケン** | 鞍の後ろ、**馬体の側面**に当て布。★**空白**（番号はレンダラが描く） |

★**128×96 にした理由**: 110px の馬体 ＋ 尾と脚の振り幅の余白。
2× にすると 256×192 で、寄りのカットでも耐えます。

### ⚠️ ★接地点は「セルの中央」ではありません（試作①で分かった）

斜め俯瞰では**馬が画面の右上へ向かって走る**ので、
★**接地している蹄はセルの左下にあります。** 実測（幅160のとき）:

```
セル 160 × 119
★接地点（下端 6px 帯の重心） x = 32.2 / y = 118
   セル中央 x = 80.0 との差 ★−47.8 px（= セル幅の −30%）
```

→ ★**契約に「接地点 (x, y)」を数値で持たせ、全コマで揃えます。**
   これを揃えないと、**影と馬がずれ、走るたびに馬が跳ねます**
   （真横のときも「胴が跳ねる」で同じ失敗をしました）。

**暫定値（128×96 のセル）**: 接地点 = **(38, 95)**。⚠️ 2コマ目以降で確定します。
