## 1. これは何か

**この1枚は手で描いた絵ではありません。** `palette.json` と `layers.json` を読んで
`mockup/still.js` が描いた**プログラムの出力**です。16進の色値も層の寸法も
このファイル内に1つもありません（役割名で引いています）。

→ **数値を差し替えれば絵が変わります。** 「もっと渋く」ではなく「`turf-3` を1段暗く」で通ります。
→ `packages/render` の `DrawCommand` に対応づけてあります（下記 §4）。

## 2. 何をどう使うか

| 使うもの | どこで |
|---|---|
| `palette.json` | アートバイブル §6 の「共有パレット」の実体。**`canvas-renderer.ts` の `PALETTE` 定数を置き換えてください** |
| `layers.json` | `band` / `parallax` コマンドを組む元。y・高さ・**速度比**・タイル幅が入っています |
| `sprites/horse-gallop.png` | 220×140 × 6コマ・横並び・背景透明。**6コマとも胴体が揃っています** |
| `sprites/contract.md` | シート契約（基準点・接地線・勝負服とゼッケンの位置・毛色の作り方） |
| `ui/spec.md` | 順位表示・実況帯・着順表・ゲージ・ハロン棒・ゴール板の寸法と余白 |
| `mockup/still.js` | ★参照実装。移植先は `canvas-renderer.ts` の `drawFrame` です |
| `mockup/layers/` | 各層を分けた PNG（01〜08 が層単体、09〜12 が背景／手前／馬群／UI） |
| `NOTES.md` | **なぜこの配色・この層構成なのか。** 調整するときはここを読んでください |

## 3. 絶対に崩さないでほしい3つ

1. **倍率は 1倍と2倍だけ。** この1枚も、奥の2段は 1×、手前の1段は 2× です。
   `still.js` に `scale` は `1|2` 以外入りません。**非整数倍は1か所もありません。**
2. **色は役割名で引く。** `palette.json` が唯一の出所です。
3. **色だけで情報を運ばない。** 先頭＝金＋**冠の形**、自馬＝金＋**「自」の文字**、
   余力＝色＋**刻みの数**、ペース＝色＋**棒の本数**。この併記は省略できません。

## 4. 描画コマンドとの対応

| `DrawCommand.kind` | この1枚のどこ |
|---|---|
| `band` / `parallax` | `layers.json` の 8層（`speedRatio` をそのまま `offset` の係数に） |
| `sprite` | 12頭。`silk` は `silk-N`、`scale` は 1 か 2 |
| `shadow` | 接地点の平たい楕円（w×0.085・高さその 1/4） |
| `effort` | 各馬の頭上の小さな帯（刻み4つ） |
| `gauge` / `cue` | 左上の1枚のパネル（**唯一の「機械」の表現**） |
| `gap` | ゲージの直下。**順位の数字を出しません** |
| `pace` | 右上（棒3本で段階も出す） |
| `pole` | ハロン棒（`speedRatio` 1.00＝馬と同じ速さ） |
| `finishLine` | 決勝線（走路の面・馬より奥）＋ゴール板（ラチの線・馬より手前） |
| `callout` | 下の紙の帯。**幅を切って手前の芝を潰していません** |
| `result` | 確定後のみ（`mockup/fixed.png`） |

## 5. まだ決めていないこと（そちらで決めていただきたい）

- **勝負服の「柄」**。地色18色（＝枠順色 D-060）だけ確定しています。柄は実在意匠を使えないので、
  「一本輪」「山形」「格子」などの**幾何の型を何種類作るか**を決めてから起こします。
- **道悪**（稍重／重／不良）。`dirt-0〜3` は入れましたが、**芝の道悪の見え方**は未設計です。
- **パドックと確定後の余韻**。今回は走行中の1枚だけです。
