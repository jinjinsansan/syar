# なぜそうしたか

**理由が分かれば、そちらで調整できます。** 判断の根拠だけを書きます。

---

## 1. 「おもちゃに見える」の正体は、彩度ではなく**層の数と明度差**でした

オーナー判定の #5 は「彩度が低くのっぺり」でしたが、**彩度を上げるとアートバイブル P-1
（平時に高彩度を使わない）に当たります。** 平時が派手だと勝負所が沈むので、上げられません。

→ **のっぺりの原因を彩度ではなく「層が3つしかないこと」だと読み替えました。**

| 前 | 後 |
|---|---|
| 空・スタンド・生垣・柵・芝（実質4層） | **8層**（空／スタンド／生垣／奥の柵／奥の芝／走路の芝／手前のラチ／ラチ内の芝） |
| 層ごとの明度差なし | **奥の層に霞を重ねた**（`$air.alpha`: スタンド 0.16 → 奥の芝 0.05 → 手前 0） |
| 芝は1色＋薄い縞 | **8階調**（`turf-0〜7`）。奥は明るく霞み、手前は暗く濃い |

**彩度は芝と空を据え置き、手前の要素（ラチ・砂煙・ゼッケン・UI）だけ上げています。**
これで「のっぺり」は取れ、P-1 も守れます。**もし平時の彩度も上げてよいなら、
`turf-2〜5` を1段上げるだけで済みます**（ここが唯一の調整点です）。

## 2. 「手前と奥の差」は霞と重なりで作りました（拡大縮小は使えないので）

不足 #4 への答えです。**ピクセルアートは非整数倍で拡大縮小できません**（D-058）。
`/still` の現行実装は `horseScale * (0.62 + depth * 0.55)` で**非整数倍に縮小していました。**
これは絵が壊れるので採れません。

→ **奥行きを、倍率ではなく次の3つで作りました:**

1. **段の y**（奥 436 / 中 520 / 手前 626）
2. **倍率は 1× と 2× の2択だけ**（奥2段が 1×、手前1段が 2×）
3. **霞**（奥の馬に `sky-3` を 10% / 4% / 0% で重ねる）

**2×の1段があるだけで「厚み」が出ます。** 12頭のうち3頭を 440×280 で描いているのが、
この1枚が「板の上」に見えない一番の理由です。

## 3. 馬群は「重ねる」ではなく「**列を割る**」ことで団子に見せました

不足 #2 への答えです。均等に並べると団子にならず、**櫛の歯**になります。
段ごとに x をずらし（奥 150/330/505/685/860、中 430/615/800/985、手前 230/660/1060）、
**段の間で 40〜60px 重なる**ようにしました。手前の3頭は 440px 幅なので必ず重なります。

## 4. 逆光は「暗くして、縁だけ光らせる」で作りました

アートバイブル §2「直線 = 逆光・砂煙で霞む」。方法は2つだけです。

- **馬体を落とす**（`$backlight.bodyMul` 0.74。手前の段だけ 0.86 — 近いほど情報が要る）
- **輪郭に光の縁**（`sky-5` のシルエットを右上へ 3px／2×なら6px ずらして後ろに置く）

**逆光にすると彩度を上げなくてもコントラストが出ます。** これが P-1 との折り合いです。

## 5. ゼッケンは「絵に描かない」ことにしました

不足 #6（番号が小さく2桁が欠ける）への答えです。

**当て布に合わせて番号を置くと、布の大きさがコマごとに 77% ばらつくので必ず破綻します**
（`dress.mjs` に実測が残っています）。

→ **レンダラがコマ内の固定位置に必ず描きます。** `(100, 62) 30×20`（1×）／`(200,124) 60×40`（2×）。
5×7 の字形を **2倍（10×14）** で置くので、**2桁でも 22×14 で必ず収まります。**
絵のほうは触りません（作り直して筋肉の陰影と手綱を失った件を繰り返さないため）。

## 6. 順位表示を「丸」から「紙の枡」に変えました

不足 #7 への答えです。アートバイブル §3 は **「UI は紙。角丸を使わない。罫線と余白で区切る」**
と定めています。**丸はこの語彙に入りません。**

→ 34px の**枡**を 4px の余白で並べ、1px の墨の罫線で囲みました。
先頭は**金＋冠の形**、自馬は**枡の下の墨線**で示します（色だけに頼らない）。
**丸のほうがよければ枡を円に戻せます**が、そのときは §3 の「角丸を使わない」を改訂してください。

## 7. ゴール前の緊張は「板を高い位置に吊る」ことで作りました

不足 #3 への答えです。決勝線と板はすでにありましたが、**両方が走路の面にあったので、
馬に隠れて見えませんでした。**

→ **決勝線は走路の面（馬より奥）、ゴール板はラチの線（馬より手前・高さ 218px の柱に吊る）**に分けました。
板が馬群の上を横切ることで、**「あと少し」が画面で分かります。**

## 8. 実況帯を全幅の帯にしませんでした

**全幅の帯にすると、手前の芝とラチという「一番手前の層」を毎回潰します。**
奥行きを8層で作っているのに、最前面をUIで塗るのは自分で壊す行為です。

→ **幅 792px の紙のパネル**にして、右下にラチと芝を残しました。

## 9. スタミナゲージと合図を**左上**に置きました

アートバイブル §9 の制約（C-6 を殺さない）です。**下に置くと、寄り（2×）のとき馬が下から
入ってくるので重なります。** 上は空しかないので、カメラが何をしても隠れません。
`OVERLAY_KINDS`（`gauge` `cue` `gap` `pace`）はすべて画面上部に集めました。

## 10. 速度比の決め方

**railFront = 1.00 を「馬と同じ速さ」の基準にしました。** 手前のラチは馬とほぼ同じ距離にあるので、
ここが 1.00 でないと馬が滑って見えます。あとは**距離の逆数を目安に等比で落としました**:

```
空 0.00 → スタンド 0.05 → 生垣 0.11 → 奥の柵 0.18 → 奥の芝 0.30 → 走路 0.55 → ラチ 1.00 → ラチ内 1.30
```

**ラチ内の芝が 1.30（＝馬より速い）のが要点です。** 馬より手前にあるものが馬より速く流れて初めて、
「自分がその内側にいる」ことが伝わります。**ここを 1.00 にすると平面に戻ります。**

## 11. 採らなかったもの

- **線遠近**（アートバイブル §3 が禁止）。走路の帯は横一直線のままです
- **CRT スキャンライン**（D-057 で撤回済み）
- **馬体での描き分け**（§3。毛色5種だけ例外として使っています）
- **実在の競馬場・馬・勝負服の意匠**。スタンド・生垣・ラチ・ハロン棒・決勝線・枠順色は
  **業界共通の作法**として採り、固有の意匠は一切入れていません
