## 1. 基準点 — ★6コマとも胴体が揃っています

**基準点はコマ内 `(133, 20)`。** これは**勝負服（青）の重心**です。

### なぜ当て布ではなく勝負服の重心なのか

現行の `dress.mjs` は**当て布（明るい無彩色）の重心**で揃えています。
`horse-gallop-220-sheet.png` で同じ規則を当てて実測したところ、

| 基準の取り方 | 6コマの y のばらつき |
|---|---|
| 下端（`position: bottom`） | **28px**（脚の伸びで跳ねる） |
| 当て布＝明るい無彩色の重心 | **41px**（★白い靴と白い袖を拾ってしまう） |
| **勝負服（hue 200〜260・彩度 0.35 以上）の重心** | **10px** |

→ この素材では**当て布の規則が使えません**（白い部分が靴・袖・当て布に分散している）。
**勝負服の重心が最も安定します**（騎手は鞍の上で動かないため）。

**次の1頭も同じ規則で揃えてください。** `still.js` の `bakeStrip` が
同じ hue 条件で勝負服を拾っているので、**塗りと整列が同じ定義を共有します。**

## 2. 接地線

**接地線はコマ内 `y = 136`。** 描画は `y = groundY - 136 × scale` で置きます。

| コマ | 外形 x | 外形 y | 最下端 |
|---|---|---|---|
| 0 | 31–203 | 3–134 | 134 |
| 1 | 24–200 | 3–135 | 135 |
| 2 | 22–200 | 4–121 | **121（★宙に浮くコマ）** |
| 3 | 11–208 | 3–134 | 134 |
| 4 | 30–200 | 0–136 | 136 |
| 5 | 31–205 | 4–139 | 139 |

★**コマ2は接地していません。** 影は `strength` を落として小さくしてください
（`DrawCommand.shadow` のコメントどおり「跳んでいることの表現」になります）。

## 3. 勝負服の塗り替え

```
条件: 彩度 ≥ 0.35 かつ hue 200〜260（＝元の絵の青）
置換: silk-N × (元の明度 / 255)
```

★**明度を掛けるのが要点です。** 単色で塗ると布の陰影が消えて「後から塗った」ように見えます。

## 4. 毛色（5種）

```
条件: 彩度 ≥ 0.18 かつ hue 8〜48（＝馬体の茶）
段:   明度 >0.62 → coat-*-0 / >0.45 → -1 / >0.28 → -2 / それ以下 → -3
割当: coat = ['kage','kurokage','kuri','ashi','ao'][馬ID % 5]
```

★**黒い部分（たてがみ・尾・脚先）は塗り替えません**（彩度が足りないため自動的に外れます）。
芦毛・青毛でも「黒い四肢」が残るのは意図どおりです。

## 5. ゼッケン — ★絵に描きません

```
位置: コマ内 (100, 62) / 30×20     （1×）
      (200, 124) / 60×40           （2×）
字形: 5×7 のドット数字（tools/lib/pixel-font.mjs）を scale×2 で
      → 2桁で 22×14（1×）。★30×20 の枠に必ず収まります
色:   紙（paper-0）の当て布＋上辺 3px に枠順色＋墨の数字
```

**当て布の実物に合わせません。** 布の大きさはコマごとに 77% ばらつくため
（`dress.mjs` の実測）、**合わせると必ず番号が伸び縮みします。**
