## 1. 視覚的アイデンティティ

### ★一行規則

> **競馬場の渋さを、ピクセルで。派手さは勝負服と「間」だけに許す。**

**視覚上の判断に迷ったら、この一行が決めます。**

### 支える3原則

| # | 原則 | 判定テスト |
|---|---|---|
| **P-1** | **抑制が既定、鮮やかさは例外** | 色を足したくなったら「これは勝負服か、仕掛けの瞬間か」を問う。**どちらでもないなら彩度を上げない** |
| **P-2** | **奥行きで没頭させ、記号で説明しない** | 情報を足したくなったら「レイヤー・光・カメラで伝わらないか」を先に問う。**アイコンとテキストは最後の手段** |
| **P-3** | **32×32 で18頭が並んでも、自分の馬が一目で分かる** | 描き込みを増やしたくなったら「18頭に並べて縮小しても成立するか」で切る |

**★P-1 は §8b の制約から来ています。** 介入の効きは V-9a が **±10%** にキャップしており、**機構では派手さを出せません。** だから**演出が体感を全部背負い、そのために平時は抑えておく必要があります。** 平時が派手だと、仕掛けの瞬間が沈みます。

## 2. 状態別のムード

| 状態 | 情緒の目標 | 光 | 空気 | エネルギー |
|---|---|---|---|---|
| **パドック / 出走前** | 品定めの静けさ | 斜光・長い影 | 湿った土、朝靄、ざわめき | 低い・張り詰めている |
| **道中** | 我慢 | 平坦・順光 | 蹄音、風、規則正しさ | 一定・単調をわざと作る |
| **★勝負所（仕掛け）** | **来た** | **一段暗くして、直後に抜ける** | 息、鞭、群れが割れる | **★ここだけ跳ねる** |
| **直線** | 決着 | 逆光・砂煙で霞む | 歓声が割れる | 最高 |
| **確定** | 余韻 | 静止・彩度がすっと落ちる | 静寂 → 掲示板の音 | 急降下 |
| **育成 / 週送り** | 手入れの時間 | 屋内・柔らかい | 藁、朝の厩舎 | 低い |
| **配合 / 血統表** | 系譜を読む | 紙面のような平坦さ | 資料室、インク | 静 |

**★勝負所だけが跳ねます。** そのために道中を意図的に単調にします。**「単調な道中」は手抜きではなく、設計です。**

## 3. 形の言語

### 馬（最重要）

- **やや実馬寄り**。頭身は保つ（デフォルメしない）。脚の長さ・首の角度は実際の競走馬のシルエットに従う
- **★個体識別は勝負服の配色のみ**。馬体で描き分けない（32×32 では不可能で、やろうとすると全部が濁る）
- **★シルエットが命**。単色に潰しても「馬が走っている」と分かること
- **脚は4フレームで嘘をつく**。実際のギャロップの正確な再現より、**接地の瞬間が分かること**を優先

### 背景

- **水平の帯**で構成する（芝／ラチ／スタンド／空）。**縦の要素は最小限**
- **多層パララックス**。手前ほど速く流れる。**奥行きは速度差だけで作る**（線遠近を描き込まない）

### UI

- **★UI は世界の一部ではなく、紙である**。マークシート（§12.5）、掲示板、血統表 — **すべて「印刷物」の語彙**で統一する
- 角丸を使わない。**罫線と余白で区切る**
- **ゲージだけが例外**（§12.6 のスタミナゲージ）。ここは唯一の「機械」の表現

## 4. 色

### 基調（48〜64色パレットの骨格）

| 役割 | 方向 | 用途 |
|---|---|---|
| **芝の緑** | 彩度を抑えた深い緑（4〜6階調） | 画面の最大面積 |
| **土の茶** | 湿りで2系統（良／道悪） | ダート・パドック |
| **空と靄** | 灰青〜灰白（3〜4階調） | 奥のレイヤー・時間帯 |
| **木と鉄** | 焦茶・鈍色 | ラチ・スタンド・掲示板 |
| **紙** | 生成り・薄墨 | **UI 全般** |
| **★勝負服** | **★高彩度をここに集中**（12〜16色） | **個体識別の唯一の手段** |

### 意味の割り当て

| 色 | 意味 | 補助（色覚多様性） |
|---|---|---|
| **金** | 重賞・G1・最上位 | **★冠マーク**（形で重複させる） |
| **赤** | 危険・故障・EP の減少 | **★下向き矢印＋音** |
| **青緑** | PP の増加・払戻 | **★上向き矢印＋音** |
| **紫** | インブリード（血統表のクロス） | **★線種を変える**（§12.2 の色付き強調は線種と併用） |
| **灰** | AI 代行中（§12.6） | **★「代行中」の文字を必ず併記** |

**★色だけで意味を運ばないでください。** 上表の補助は省略不可です。**特に EP と PP の区別（憲法 §0.2）は、色で分けたつもりにならないこと。**

### 道悪の表現

**`heavy_aptitude` は実装され、D-052 で本番経路にも接続されました。** **馬場状態が画面から分かること**が要ります。

- 良 → 稍重 → 重 → 不良 で **土の彩度と反射**を段階的に変える
- **蹄が跳ね上げる粒**の量と色を変える

## 5. 馬のアセット仕様

| 項目 | 値 |
|---|---|
| スプライト | **32×32 前後**（正典 §12.1） |
| ギャロップ | **4〜6フレーム** |
| 必要な動作 | ギャロップ（通常／仕掛け中／脱落）・パドック待機・ゴール後 |
| **★個体差** | **勝負服のみ**。馬体は共通スプライトの色替えで足りるかを、まず1頭で検証する |

**★「馬体は共通で足りるか」は P4 の最初の実測項目です。** 足りるなら、アセット量は**勝負服のパターン数**で決まります。足りないなら、頭数×パターン数になり、初回ロード予算が桁で変わります。

## 6. アセット標準

| 項目 | 規則 |
|---|---|
| 形式 | **スプライトシート PNG**（`*-sheet.png`。image-cockpit の出力形式） |
| **★生成ジョブ** | **シートと同じ場所・同じ名前で JSON を必ずコミット**（`codex-handoff/inbox/` のもの） |
| 命名 | `<対象>-<動作>-sheet.png` / 同名 `.json` |
| パレット | **1つのパレットファイルを共有**し、全アセットがそこから色を取る |
| シート契約 | **フレーム寸法・列数・フレーム数・基準点**を1頭目で確定し、以後変えない |

**★生成ジョブをコミットする理由**: `image-cockpit` は `.gitignore` されているので、**star に残るのは出力だけ**です。**プロンプトの無いアセットは出所の無い証拠**で、「同じ絵柄でもう1頭」も修正もできなくなります（R-23 と同じ理屈）。

## 7. 参照 — 何を採り、何を採らないか

| 参照 | ★採るもの | ★採らないもの |
|---|---|---|
| **現代のピクセルアート**（Dead Cells / Octopath 系） | **限定色でも光と奥行きが作れるという事実**。パララックスの層の切り方 | ファンタジー的な色彩。**この作品は土と草である** |
| **競馬中継の画作り** | **横からの長回し**、逆光の直線、砂煙。**カメラが寄る/引くタイミング** | 実況のうるささ。3Dの追従 |
| **紙の競馬新聞・マークシート** | **UI の語彙**（罫線・等幅・余白・印刷物の質感） | 情報密度。**画面は紙より少なく** |
| **80〜90年代のスポーツゲームの「間」** | **決着直前に音を抜く**、結果表示の溜め | ドット絵の粗さそのもの。**16色に戻らない** |

### ★禁止事項

| # | 禁止 |
|---|---|
| 1 | **実在の競走馬・馬主・団体の名称／ロゴ／勝負服の再現**（憲法 §0.1） |
| 2 | **既存の競馬ゲーム（アーケードのメダルゲーム等）の画面構成の模倣**。**差別化が路線選択の目的**であり、似せた時点で目的を失う |
| 3 | **CRT スキャンラインを既定で全画面に乗せること**（D-057 で撤回。局所的な演出としてのみ可） |
| 4 | **平時に高彩度を使うこと**（P-1） |
| 5 | **色だけで意味を運ぶこと**（§4） |
| 6 | **馬体で個体を描き分けること**（§3・32×32 で破綻する） |

## 8. この文書の使い方

1. **`image-cockpit` のプロンプトは、§1 の一行規則と §4 のパレットを必ず含める**
2. **新しいアセットを作る前に §7 の禁止事項を通す**
3. **§5 の「馬体は共通で足りるか」を最初に検証する** — アセット量と初回ロード予算がここで決まる
4. **迷ったら §1 の3原則の判定テストに当てる**

> **未確定**: 具体的な色値（16進）は、1頭目の試作を見てから確定します。
> **理由**: 画面に並べる前に色を決めると、必ず作り直しになるためです。
