# カットの切り替えで何を見せるか

★**`packages/render/src/camera.ts` のカット表に「乗せる」ものだけを書きます。** カット表自体は変えません。

★**秒は「切り替わってからの経過」にだけ使います。** 切り替わる位置は
`cutsFor(course)` が返す `fromMetersLeft` です（★書き写しません）。

---

## 1. 切り替えの瞬間に何を出すか

| カット | 出すもの | 尺 | 理由 |
|---|---|---|---|
| 発走 | ★**枠入りの帯**（紙・全幅）→ 旗が振られたら**発走の帯** | 帯 1.2s → 0.4s で消える | 音が無くても「始まる」と分かる（§RESEARCH-1） |
| 隊列形成 | ★**地名帯**「隊列」＋残り距離 | 0.6s | ここは何も起きない区間。**帯だけで「移った」と伝える** |
| 向正面 | ★**地名帯**「向正面」＋残り距離／★**景色が変わる**（スタンドの裏・樹林） | 0.6s | ★**景色が主役。帯は補助** |
| 3角 | ★**地名帯**「3 角」／★**回頭が始まる**（`$cornerMotion` の pan を 1.2s で 0 → 0.48） | 0.6s | 帯より**背景が逆流し始める**ほうが強い |
| 4角 | ★**地名帯**「4 角」／★**標識**が奥の柵の線を流れる | 0.6s | 4角は「もうすぐ直線」の合図 |
| 直線 | ★**残り距離の大きな表示**（画面中央・0.5s で消える）／★逆光とグレアが立ち上がる（0.8s で補間） | 0.5s | ★**ここだけ画面中央を使います。** 全レースで1回だけなので効きます |
| 追い比べ | ★何も出さない | — | ★**足すのではなく、引く。** 帯も標識も出さず、馬とゲージだけにする |

★**地名帯は `ui/cut-badge.png` の意匠**（紙・角丸なし・左端に墨の縦帯）。
位置は **(24, 560) 300×52**。★実況帯（648）とゲージ（22）を避けています。

## 2. 出さないもの ★これが大事です

| 出さないもの | 理由 |
|---|---|
| ★カット名の常時表示 | 帯は**0.6秒だけ**。出しっぱなしにすると、切り替わったことが伝わらなくなります |
| ★画面のフラッシュ・ワイプ | アートバイブル §3 の語彙にありません。**切り替えは「切り替え」で足ります** |
| ★カメラのブレ | ピクセルが非整数でずれます（D-058） |
| ★残り距離の常時カウント | ハロン棒が横切ることで分かります。**数字を出すと目がそちらに行きます** |

## 3. 繋ぎ方（`blendSec` に合わせる）

`camera.ts` は `blendSec: 0` を**切り替え**、正の値を**補間**としています。
★**演出もそれに合わせます。**

| `blendSec` | 演出 |
|---|---|
| **0（切り替え）** | ★**景色を丸ごと差し替える**。帯は切り替わった**次のフレーム**から 0.6s |
| **正（補間）** | ★**景色は変えない。** グレア・霞・pan だけを同じ秒数で補間する |

⚠️ **補間中に景色を差し替えると、2つの区間が混ざって見えます。**
`blendSec > 0` のカット（隊列形成 1.2s / 3角 1.0s / 追い比べ 2.5s）では、
**`section` を変えないでください。**

→ 具体的には: `section` を切り替えてよいのは **`blendSec === 0` のカットだけ**です
（発走・向正面・4角・直線）。

## 4. 区間と `section` の対応

| `camera.ts` のカット | `layers.json` の `section` |
|---|---|
| 発走 | `gate` |
| 隊列形成 | `homestretch`（★スタンド前発走の想定。変えない） |
| 向正面 | `backstretch` |
| 3角 | `corner`（★`blendSec 1.0` なので、pan だけ補間して景色は 4角 で切り替え）|
| 4角 | `corner` |
| 直線 | `homestretch` |
| 追い比べ | `homestretch`（変えない） |

⚠️ ★**3角のカットは `blendSec: 1.0` です。** ここで景色を差し替えると混ざります。
→ **3角に入った時点で pan の補間だけ始め、景色は 4角（`blendSec: 0`）で切り替えてください。**

## 5. 発走の時間割 ★推測を含みます

| t | 起きること | 出典 |
|---|---|---|
| 0.0s | 輪乗り。ゲートは閉じている（`scenes/gate-closed.png`） | ★出典あり |
| — | スターターが台に上がり、**赤い旗を振る** | ★出典あり |
| +0.0s | ★**ファンファーレの帯**（`scenes/gate-fanfare.png`）。旗が両脇に出る | ★出典あり（形式） |
| +1.2s | 帯が上下へ抜ける | ★**推測**（演出の都合） |
| +3.0s | ★**ゲートが開く**（`scenes/gate-open.png`） | ★**推測** — ⚠️ **実際は枠入りに数十秒〜数分かかり、固定の秒数はありません**（RESEARCH §1） |
| +3.0s〜 | 砂煙。★ゲートは馬より**後ろ**に置く（馬は前へ出ている） | — |
| +3.6s | ゲートが画面外へ流れきる（`speedRatio` を 0 → 1.0 に 0.6s で補間） | ★**推測** |

★**枠入りの長さは実装側で決めてください。** 私が秒を置いたのは「間が要る」ことを示すためで、
**この 3.0 秒に根拠はありません。**
