## [x] R-1（最優先）Web 画面の基調を「明るいアーケード筐体風」に変える — 2026-08-19

**理由**: Web 画面（番組表／レース詳細／オッズ／牧場ホーム／馬詳細／調教／出走登録／投票／記録／景品交換）が中継 HUD と同じ暗色基調で起こされているが、オーナーが目指すのは**アーケードの競馬メダルゲーム筐体の UI**（明るい・派手・大きな数字・光沢）。暗色では「それ」に見えない。
**対象外**: レース中継 HUD（映像に重ねる黒い帯・金）は合格なので**そのまま**。

### 目指す基調
- **明るい。** 地は白〜アイボリー〜明るい水色のグラデーション（暗い地は使わない）。パネルは白地に濃い縁、タイトル帯は青や赤の濃色に白抜き文字
- **派手で光沢がある。** ボタンとタイトル帯はベベル／グロス（上が明るく下が濃い 2 段グラデ）、縁は 2〜3px の濃色、角は大きめの丸み（8〜12px）
- **数字がとにかく大きい。** オッズ・EP/PP・残り時間・着順は 28〜64px の太いゴシック。色は 金／赤／青 をはっきり使い分け（例: 順位=赤、金額=金、時刻=青）
- **情報密度は高いが、罫線と帯で区画がはっきり**（賑やかだが読める配置）
- 枠色 1〜8（白・黒・赤・青・黄・緑・橙・桃）は据え置き。馬番は枠色の塗り＋白縁の大きめバッジ
- 芝の緑・空の青・ゴールドを差し色に。金は「勝ち・賞金・主ボタン」に限定（HUD と同じ規律）
- 文字は system-ui 太字でよい（将来、丸ゴシック系の専用書体に差し替えられるようフォントはトークン 1 か所に）
- **実在の製品名・団体名は書かない**（憲法 §0.1）。特徴で指定する

### やること
1. **トークンを 2 系統に分ける**: `styles.css` に `[data-theme="arcade"]`（Web 用・明るい）を追加し、既存の暗色は HUD 用として残す。色・影・角丸・ベベル（`linear-gradient` 2 段＋`box-shadow`）を全部トークンに
2. **まず 3 枚だけ差し替え**: `components/program-board`（番組表）・`components/stable-home`（牧場ホーム）・`components/bet-sheet`（投票）。各カードの先頭の `<div>` に `data-theme="arcade"` を付けて切り替える
3. 各カードの実装表を更新（地色・縁・角丸・グロスの値を明記）
4. 憲法はそのまま: EP と PP を合算しない／「購入・チャージ・換金・円」を使わない／実在名を使わない
5. 3 枚がオーナー合格になったら、残り 7 枚（race-detail / odds-board / horse-detail / training / race-entry / records / prize-exchange）へ展開

### 完了報告（2026-08-19 / Claude Design）

- `styles.css` に `[data-theme="arcade"]` を追加（HUD の暗色トークンはそのまま残置）。色・グロス（2 段グラデ）・影・角丸・縁・数字の色分け・書体を全部トークン化。**書体は `--a-jp` / `--a-num` の 2 か所だけ**なので、丸ゴシック系の専用書体が決まったらここを差し替えるだけで全 Web 画面に反映されます。
- 3 枚を差し替え済み: `components/program-board`・`components/stable-home`・`components/bet-sheet`（各カード最上位の `<div>` に `data-theme="arcade"`）。実装表も地色・縁・角丸・グロスの値つきで更新。
- 数字の色分けを全 Web 画面共通の規則として明記: **時刻・週・残り = 青 #0f56ab / 金額・払戻 = 金 #a9741a / 順位・締切・警告 = 赤 #d62f26**。
- 憲法は維持（EP と PP は別カプセル・合算なし、「購入／チャージ／換金／円」不使用、実在名なし、自馬レースは投票不可、不的中は静かな画面）。
- Q: 「残り 7 枚（race-detail / odds-board / horse-detail / training / race-entry / records / prize-exchange）」は、この 3 枚がオーナー合格になり次第、同じトークンで展開します。**合格の可否だけこの項目の下に書いてください。**

### 判定（2026-08-19 / オーナー → Claude Code 記入）

- **合格。** 3 枚とも実装して開発サーバーで確認済み（`apps/web/src/app/page.tsx`・`stable/page.tsx`・`races/[id]/bet/page.tsx`、トークンは `globals.css` の `[data-theme="arcade"]`）。オーナー評「凄くゲーム感がある」。
- そのまま **残り 7 枚へ展開してください（下の R-2）**。
