2. 新しいシートを納品するときの受け入れ条件
① 1 行 = 8 コマ（斜め視点は 4 コマ）を横並び。行を増やす場合は「上から枠色 1→8」の順。
② コマ幅は整数。シート幅 = コマ幅 × コマ数（端に余白を入れない）。
③ 接地点は全コマで同一。脚を畳んだコマだけ体高が変わる（脈動する）状態は不可。
④ 表示倍率の基準は「8 枚中の最大不透明高」。これを referenceHeight として一定にする。
⑤ 透過 PNG。クロマキー原版から抜いた場合、被写体内部にキー色が残っていないこと。
⑥ 勝負服・ゼッケン・枠色は差し替え可能な構造（別レイヤーか無地マスク）を保つ。
⑦ 8 コマは pose01 → pose08 → pose01 が連続する完歩 1 周期。飛びがないこと。
3. 命名
horse-jockey-<view>-v<n>-pose<01..08>.png　　view = side / rear / diag-front / diag-rear / high-diag / far
シート化: horse-jockey-<view>-v<n>-sheet.png（1 行 × コマ数）
マスク: 同名 + -mask-silks.png / -mask-bib.png
4. 行と枠色の対応（描画側の規約）
row = Number(frameRoleOf(gate, fieldSize).slice(6)) − 1　→ 0..7 が枠色 1..8。
枠色は「帽子・鞍布」に載る色。馬体色は行で変えない（毛色は filter か別素材で）。
⚠ 寄り用シートを縮小して引きに使わない（半端な倍率で画素格子が合わず輪郭が濁る）。引きは SHEET_FAR として別に描く。
⚠ セル寸法・コマ数を描画コードに直書きしない。必ず SheetSpec 経由で渡す。
