## 0. 結論（先に）

参照作品は **「本体はゲームセンターの筐体、Web は連動サイト」** という二層構造で、**レース参加（生産・調教・出走・馬券）は筐体でしか行えない**。Web（連動サイト）は「成績・所有馬・番組表・ランキングの閲覧」＋「一部のオンライン専用コンテンツ」。

したがって導線は次の 2 本に分かれる。

| 導線 | 入口 | 終点 |
| --- | --- | --- |
| A. 初めての人 | 公式 TOP → 「はじめての方はこちら」LP → **店舗を探す → IC カードを用意 → メダル口座開設 → 筐体に座ってアカウント発行（秘書の案内）** | 筐体でプレイ開始 |
| B. 稼働中の人（Web） | 公式 TOP → 連動サイトへログイン（筐体で発行した 11 桁アカウント＋パスワード）→ 厩舎選択 → **会員ホーム** | 成績・番組表・ランキングの確認／オンライン専用コンテンツ |

STAR は Web 完結なので、**A の「筐体」を Web の「アカウント作成」に置き換え、B の会員ホームを「ログイン後の番組表ハブ」に重ねる**のが対応関係になる（§6）。

## 1. 公式 TOP からの導線（未ログイン）

1. **TOP**（前回調査 `docs/lp-reference-research-20260819.md`）: ヒーロー直下の大ボタン 4 つ = **はじめての方はこちら／プレイガイド／イベントカレンダー／連動サイトへログイン**。ニュース 5 件、ランキング・大会結果、設置店舗・マンガ・問い合わせ。
2. **はじめての方はこちら（LP）** → 下部「5 つのミッション」の 1 番が **設置店舗を探す**、2・3 がチュートリアル動画、4 がマンガ、5 がおすすめポイントチェック。
3. **「はじめてみよう」ページ**（プレイガイド内）= 実際の開始手順。見出しの順序がそのまま導線:
   1. 設置店舗を探そう（店舗一覧へ）
   2. IC カードを用意しよう（販売機／店舗スタッフから購入。動画あり）
   3. メダル口座を開設しよう（電子メダル用。店舗スタッフ対応）
   4. 筐体のアカウントを発行して厩舎を作成しよう（サテライトに座る → カードを読ませる → **秘書の案内に従ってアカウント作成**）
   5. 「さらに遊び方を確認したい方は → ゲームの流れ」
   → **「登録」は Web ではなく筐体で行う。Web 側のユーザー登録フォームは存在しない。**

## 2. 筐体でのゲームの流れ（レース参加に至る導線）

### 2.1 時間構造 — 1 レース（約 4 分）の間に 2 つのゲームが並行
- 画面は **左「ベット画面」／右「オーナー画面」** の 2 面。それぞれ独立した時間を持つ。
- **ベット時間**（馬券を買える時間。画面上部に残り秒 `BET 063`） → **レース中** → **リザルト** → 次のレース。
- **オーナー時間**（育成操作ができる時間。上部に残り秒 `OWNER 174`）。レース開始で育成操作が制限され、次のレース開始まで続く。
- 連動サイトの番組表（§4）では **4 分おき**に「全国レース」と「店内レース」が交互、さらに同時刻に **メイン／サブ／サテライト** の 3 レースが並行開催。

### 2.2 ベットゲーム（馬券）の流れ
- ベット画面: ①残り時間 ②レース情報（格・名称・場・芝ダ・距離・天候・馬場＋出走表: 枠・馬番・馬名・騎手・単勝・人気・評価記号・短評）③カメラ ④コンフィグ ⑤サブレース切替 ⑥購入馬券の確認 ⑦レース説明のスクロール ⑧ベット単位（1〜1000 / 三連単は 0.1〜100）⑨券種切替（単複・枠連・馬連・馬単・ワイド・3連複・3連単・ライド・サイド・エール）⑩キャンセル
- 流れ: 馬券を選ぶ → ベット → 締切 → レース観戦 → 払戻。**メダル（店の通貨）で投票する。**

### 2.3 オーナーゲーム（育成）の流れ
- オーナー画面のホーム = **牧場の俯瞰絵**に「厩舎／牧場／事務所／★セール」のテキストボタン。下段に **馬房 6 つ**（「馬がいません」）＋ペット小屋。下部タブ: ホーム／厩舎／牧場／★セール／事務所、情報／クエスト／ミッション／スクラッチ／連動サイト／株券閲覧。上部: レーシングプログラム／ランキング／ラリー／コンフィグ／ヘルプ／特殊レース／ショップ／メダル口座／離席／ゲーム終了、プレゼント・お知らせ、厩舎名＋レベル。
- **最初の馬の入手** = 「通常生産」: **種牡馬と繁殖牝馬を 1 頭ずつ選んで「生産」**（スターホースカード／株券／自家生産馬でフィルタ・ソート、おすすめ機能・ロック機能あり）。ほかに ★セール（期間限定の配合素材）・確定ガチャ。
- **デビュー**: 生産直後は「デビュー前」→「デビュー」ボタン → **入厩選択** → **条件戦選択**（3 歳は 3 勝・古馬は 4 勝するまで条件戦）→ 条件戦ごとに一定確率で **適性が判明** → 調教パートナー選択（カード所持時）。
- **育成ループ**: 調教・飼葉（オーナー時間の中で毎レース行える）・牧場・馬装・騎手。
- **出走**: オーナー画面の「出走」ボタン（**メダルが必要**）→ レース選択 → 枠の仕組み（**優先枠 ＞ 通常枠 ＞ 抽選枠**。優先出走権は対象レース勝利で獲得。フルゲート超過は除外）→ 騎乗騎手依頼（関東／関西／招待／優先契約）→ 「出走登録」ボタン（**登録料＝メダル**。賞金が高いレースほど高い／5 着以内で賞金メダル／1 頭を 2 レース同時登録は不可／前ゲームまで騎手変更可）。
- **引退**: 「引退」ボタン → 引退式 → **殿堂入り**で殿堂馬として登録（次世代へ＝配合素材・殿堂馬レース）。

## 5. 設計ルールとして読み取れること

1. **LP と会員ホームは完全に別ページ**。LP は「何のゲームか＋始め方の手順」、会員ホームは「自分の状態＋開催状況＋ショートカット」。
2. **始め方は番号付きの手順**（店舗→カード→口座→アカウント）。動画を各手順に添える。
3. **レースは常時・高頻度に回る時計**（4 分おき・並行開催）。ユーザーは「次のレース」に合わせて育成操作を終える構造＝**時間の主語はレースの時計**。
4. 最初の馬は **自分で配合して作る**（種牡馬×繁殖牝馬のカタログから選ぶ）。デビュー前→入厩→条件戦という段階がある。
5. 出走は **登録料（メダル）＋枠の仕組み（優先/通常/抽選）＋騎手依頼**。賞金は 5 着まで。
6. 馬券とオーナーを **別画面・別時間**で並行させ、どちらか片方だけでも遊べる。
7. 会員ホームは **「アカウント」「厩舎」「開催状況」「ショートカット」の 4 カード＋サイドバー 6 分類**。通貨の履歴は「通帳」を種類ごとに分ける（STAR の EP/PP を分ける方針と同じ発想）。
8. 有料要素（石・月額・セール）は **別分類のサイドバーに隔離**し、ホームの主役にはしない。→ STAR は参加ポイントを売らない前提なので、ここは「景品交換」だけが残る。

## 6. STAR への当てはめ（提案）

今の STAR の導線: `/`（LP）→ 「無料ではじめる」→ `/signup`（準備中）→ ログイン後 `/races`（番組表）→ `/stable`・`/training`・`/entry`・`/races/[id]/bet`・`/records`・`/prizes`。参照作品と比べて **足りないのは「最初の馬を迎える」「ログイン後ホーム」「始め方の手順ページ」** の 3 つ。

### 6.1 始め方（A 導線）を Web に置換
| 参照作品 | STAR 案 |
| --- | --- |
| 店舗を探す | （不要） |
| IC カードを用意 | メールでアカウント作成（`/signup`） |
| メダル口座開設 | 初期の参加ポイント付与（正典の初期 EP。**販売しない**） |
| 筐体でアカウント発行・厩舎作成（秘書の案内） | **初回セットアップ**: 厩舎名（牧場名）・勝負服の色 → **最初の馬を迎える**（配合 or セリ。正典 §配合／セリの規定に従う。LP の 5 ステップ「セリで 1 頭選びます」と整合させる） |
| 通常生産 → デビュー → 入厩 → 条件戦 | 配合 → （デビュー前）→ 調教 → 出走登録（格の合うレース） |

### 6.2 ログイン後ホーム（B 導線）
- `/races`（番組表）をハブとして残しつつ、上に **4 カード**を足す案: ①アカウント（EP／PP を**別カプセル**・お知らせ）②わたしの牧場（牧場名・所有頭数・今週の未指示数・次走）③開催状況（次の発走・自馬の出走予定・投票中の馬券）④ショートカット（調教／出走登録／記録／景品交換）
- または「ホーム」を `/home` として別に作り、番組表は `/races` のまま（参照作品は **ホームと番組表を分けている**）。→ **オーナー判断**
- 番組表の時刻表は参照作品のように **行＝発走時刻・列＝同時開催** にできるが、STAR は 10 分に 1 レースなので今の 1 列で足りる。

### 6.3 レース参加の導線で取り込めるもの
- 出走登録の **枠の考え方**（優先／通常／抽選）と **除外** — 正典に無ければ照会（今は先着）。
- **賞金 5 着まで**・登録料は賞金額に比例 — 正典 §賞金表と突合（照会）。
- 騎手依頼 — STAR は騎手なし（正典どおり）。
- ベット画面の **評価記号・短評** — STAR は「みんなの投票状況」で代替（オッズに影響させない）。

### 6.4 今すぐ直せる小物
- LP 5 ステップの 2「最初の馬を迎える／セリで 1 頭選びます」の行き先を、初回セットアップ画面ができるまで `/stable` ではなく `/signup`（準備中）に揃える（いまは `/stable` のデモ牧場に飛ぶ）
- `/signup` 準備中ページに「登録後の流れ（牧場名 → 最初の馬 → 調教 → 出走登録 → 中継）」を番号つきで書く

## 6.5 正典（STAR_SPEC_v2.0）との突合
- §12.2 画面一覧では **「牧場（ホーム）＝所有馬一覧・今週の指示待ち馬にバッジ」がログイン後のホーム**。番組表は画面一覧に無い（実装側が LP/番組表を先に作った）。→ 参照作品の「会員ホーム」に相当するのは **`/stable`（わたしの馬）** が正典どおり。ログイン後は `/stable` へ送り、番組表は「出走登録／投票」の導線から入る形が正典に沿う。
- **「セリ」は正典に存在しない。** 馬の入手は §6 配合・§12.2 配合／種牡馬市場（P5）。新規ユーザーが最初の馬をどう得るかは正典に規定が無い → **照会**（LP の 5 ステップ 2「セリで 1 頭選びます」はデザイナーの案であり、正典確定まで文言を「最初の馬を迎える（方法は準備中）」に弱める）。
- 初期 EP の付与は §3.2 の供給経路（デイリーログイン等）にあり、販売は無い。登録時の付与額は未規定 → 照会。
- 出走の枠（優先／通常／抽選）・除外・賞金の着順範囲は §8〜§10 を突合して差分だけ照会。
