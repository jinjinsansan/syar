# Broadcast V2 根本再設計仕様

更新日: 2026-08-17  
目的: `/race` の固定横スクロール描画を廃止し、参考映像と同じ「コース上を走る馬を複数の中継カメラで撮る」構造へ置換する。

## 維持するもの

- `@star/race-engine` が決める位置、レーン、着順、スタミナ、タイム
- 合格済みの芝・背景・観客席・馬・騎手の画風と情報密度
- タイトル背景、実況者、ゲート背景
- v6真横馬素材の品質基準

## 廃止するもの

- 一枚背景を横帯へ分割して動かすだけの疑似パララックス
- コーナー名を表示しながら真横の馬を同じ場所で走らせる方式
- カメラ切替時に馬群を別の画面座標へ再配置する方式
- 上位3〜5頭だけを説明なく抽出する道中カット
- `fixed2DPackLayout` を本番レースの主座標として使うこと

## 正規データフロー

```text
race-engine (s, w, finish time)
  -> replayPositionModel
  -> ovalCourse + posOf(s, w)
  -> broadcastV2ShotAt(segment, race state)
  -> broadcastCamera / PerspectiveCamera
  -> project(world position)
  -> direction-specific horse frame
  -> world + horse + shadow + kickup + broadcast UI
```

馬の画面座標、縮尺、奥行き順はすべて同じ透視カメラから導出する。カットごとの手置き座標は禁止する。

## ショット構成

| 区間 | カメラ | 馬素材 | 役割 |
|---|---|---|---|
| ゲート待機 | 正面寄り低位置 | ゲート内専用 | 緊張、全馬の存在確認 |
| 発走 | 低い横／斜め | side-v6 | 頭・首・前脚・胴体が連続して抜ける |
| 発走追走 | 低いサイド追従 | side-v6 | 密集を維持しながら隊列形成 |
| 第1コーナー | 斜め前 | diag-front-v2 | 接近する馬群、内外差 |
| 第2コーナー | 高所俯瞰 | high-diag-v2 | 曲率、全頭、出口方向 |
| 向正面 | 長いサイド追従 | side-v6 | 位置取りと前後差 |
| 第3コーナー | 斜め後方 | diag-rear-v2 | ペース上昇、馬群圧縮 |
| 第4コーナー | 高所斜め | high-diag-v2 | 直線へ向く軌道、進路 |
| 最終直線 | 低いサイド＋寄り | side-v6 | 追い比べ、芝蹴り、速度 |
| ゴール | 決勝線固定＋追従 | side-v6 | 全馬通過 |
| ランアウト | 勝馬追従 | side-v6 | 減速せず画面外へ進む |
| 勝者紹介 | 勝馬単独 | side-v6 | 1着、馬名、騎手、タイム |

## 必須アセット

方向別素材は旧ピクセル素材を流用せず、v6真横馬と同じ解像感・陰影・馬体・騎手品質で制作する。

- `horse-jockey-diag-front-v2-*` 8フレーム
- `horse-jockey-diag-rear-v2-*` 8フレーム
- `horse-jockey-high-diag-v2-*` 8フレーム
- ゲート前景マスク／扉レイヤー
- コーナー用の高品質テクスチャ素材（背景そのものではなく世界投影へ重ねる質感）

## 連続性の規約

- カット前後で `s` と `w` は一切変更しない。
- カットは0.30〜0.45秒のブレンドを標準とし、同じ馬の旧画面位置と新画面位置を補間する。
- カメラの注視距離は馬群の外れ値を除いた平均で決め、先頭1頭の微小変動で振らせない。
- 発走から向正面までは全頭を保持する。
- 直線の寄りでも後続を同一ワールドに残し、画面外になる理由をカメラ投影で説明できること。
- 背景運動はカメラと世界座標の相対運動から生じさせ、時刻だけで画像を流さない。

## 100点の受入条件

1. 参考映像と同じ時刻カテゴリで、発走・横追従・正面寄り・俯瞰コーナー・斜め直線・ゴールへ変化する。
2. 任意フレームで馬の脚が芝へ接地し、影と芝蹴りが同じ投影点へ付く。
3. 第1〜第4コーナーでラチが曲がり、馬の進行方向と画面上の軌道が一致する。
4. カット前後で同じ馬が消失・瞬間移動・別方向へ反転しない。
5. 背景、ラチ、距離標、スタンドがカメラ運動に応じて移動する。
6. 発走前から全馬が存在し、ゲートから同じ個体が連続して出る。
7. ゴール後に全馬が決勝線を通過し、勝馬単独追従と正式結果へ遷移する。
8. 既存の確定着順・タイム・レーン・スタミナを描画側で改変しない。
9. 主要境界の自動テスト、時刻別スクリーンショット、通し動画の3種類で検証する。
10. ユーザー通し目視で参考映像との本質的な差が解消されたと判断されるまで完了扱いにしない。

## 2026-08-17 実レース時系列監査

- シード42の確定レースを0.25秒刻み、合計381フレームでV2へ投影。
- カット遷移は次の6回。各遷移直後の画面外消失はすべて0頭。
  1. 発走追従 → 向正面
  2. 向正面 → 第3コーナー斜め後方
  3. 第3コーナー → 第4コーナー高所俯瞰
  4. 第4コーナー → 最後の直線
  5. 最後の直線 → ゴール前
  6. ゴール前 → 勝ち馬追従
- 初回監査では画面外判定266フレーム。原因は直線・ゴールで上位1〜5頭だけを注視していたこと。
- 第4コーナーからゴールまでも全馬群を注視し、先頭と最後尾の中点をカメラ中心にするよう修正。
- 再較正後の最終監査結果:
  - `timeline samples=381`
  - `transitions=6`
  - `anomalies=0`
- 詳細値は `out/broadcast-v2-audit/timeline-metrics.json` に保存。
