# レース演出・高品質2D再構築計画

作成日: 2026-08-17  
対象: `apps/web/src/app/race` / `packages/render`  
品質基準: `apps/web/public/art/starting-gate-side-v1.png`

## 1. 目的

承認済みゲート画像と同じ情報密度・光源・質感で、カットインからゴールまでのレース演出を統一する。
高解像度PNGを既存の簡易透視投影へ縮小配置する方式は撤回し、高品質素材専用の固定2Dカメラ描画器を構築する。

## 2. 今回判明した失敗原因

1. 約1400×800pxの馬を約140×80pxまで縮小し、細部を消していた。
2. 12頭を狭い範囲へ重ね、輪郭・脚・騎手を相互に潰していた。
3. 個別生成した8姿勢を、実表示サイズと連続再生で監査せず組み込んだ。
4. ゲート背景は高品質画像だが、道中背景は簡易プロシージャル描画のままだった。
5. 高品質素材がない視点で旧馬素材へ戻り、画風が切り替わっていた。
6. 基準個体の白灰色騎手を全頭へ複製し、勝負服・帽子・ゼッケン差分がなかった。
7. HTTP 200・型検査・単体テストを、目視品質の合格と誤認した。

## 3. 「100点」の合格条件

以下をすべて満たすまで、開発サーバーで完成確認を依頼しない。

- 馬・騎手・芝・ラチ・スタンド・空の描画密度が承認済みゲート画像と一致する。
- 1頭を静止表示したとき、承認済み透過PNGと同じ顔・馬体・馬具が判別できる。
- 8コマをループ再生しても、馬体の大きさ・顔・鞍・騎手がちらつかない。
- 実表示で脚が4本として読め、輪郭が泥状に潰れない。
- 12頭表示でも、少なくとも先頭群・中団・後方群と各騎手色が判別できる。
- 全カットで旧スプライトへ戻らない。
- 勝負服・帽子・ゼッケンが馬ごとに区別できる。
- カットイン→ゲート→発走→道中→直線→ゴールの画風と時間が連続する。
- 着順・距離・スタミナは既存レースエンジンの値をそのまま使用する。
- 型検査・回帰テストに加え、基準時刻の静止画比較と連続再生監査に合格する。

## 5. 実装上の禁止事項

- HTTP 200だけで完成と判断しない。
- 高品質素材がない視点を旧素材で代用しない。
- 12頭全体表示だけで単馬品質を評価しない。
- 原画を無条件に10分の1まで縮小しない。
- テスト成功を目視品質の代替にしない。
- 合格前の途中状態を「完成」と表現しない。
