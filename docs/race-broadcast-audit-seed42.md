## 全編・複数距離ゲート

0.25秒刻みと厳密な最終時刻を対象に、表示頭数12・画面外切れ0を機械判定した。

| 距離 | サンプル数 | 検出ショット族 | 失敗 |
|---:|---:|---:|---:|
| 1200m | 313 | 8 | 0 |
| 1600m | 371 | 9 | 0 |
| 2000m | 431 | 9 | 0 |
| 2400m | 494 | 9 | 0 |
| 3000m | 591 | 9 | 0 |

ゴール後1.2秒のランアウトを含む。通常ショットは全馬、winnerショットは確定1着馬を必須対象にする。1600m・3000mの18頭も計957サンプルで失敗0。

### 左右回り

右回りも1200 / 1600 / 2000 / 2400 / 3000mの12頭で全編監査した。最初の3000m監査ではcorner-chaseの1頭が画面下へ最大約6px切れる14フレームを検出したため、3000m側の距離適応プリセットだけに縦余白を追加した。

修正後は右回り5距離に加え、1600m・3000mの18頭端ケースも失敗0。右回りsideショットは進行方向とスプライトの向きがともに画面右向きであることを代表画像で確認した。

### 画面座標Motion gate

各0.25秒サンプルで馬の足元座標と表示高を比較する。意図的なカット切替は別記録とし、同一ショット内だけ次を失敗条件にする。

- 発走後1秒を除き、1サンプルで80pxを超える移動
- 発走後1秒を除き、表示高が1.25倍を超えて変化

左右両回り×5距離の全10条件で失敗0。同一ショット内の最大移動は左1600mの43.6px、最大表示高変化は右2000mの1.055倍だった。発走直後はゲート離脱の加速区間として分離し、最大212.2pxを記録する。

ショット定義に残っていた未実装のblend指定は撤去し、現行の中継文法どおり全切替を明示的なcutへ統一した。

### 馬場キックアップ

芝・ダートと馬場状態から決定的な強度を返す`trackKickupIntensity()`を追加した。良芝は0、荒れた芝は芝片、ダートは乾燥時の土煙から不良時の強い泥跳ねまで段階的に増やす。

粒子は馬番と脚フレームから位置を決め、馬の後方のコース座標を同じ透視投影へ通す。同じ入力では同じ粒子配置になり、画面座標への貼り付けや追加乱数は使わない。不良ダート1600m・12頭の全編Framing / Motion gateは失敗0。

終盤3ショットは1600〜3000mでカメラ距離・高さ・FOVを連続補間する。短距離の寄りを維持しつつ、長距離の縦長隊列だけを必要量引く。

## この監査で直した不具合

- `corner-chase`が先頭争いだけを注視し、後続6頭が画面外へ出ていた。注視対象を馬群へ変更した。
- `straight-wide`の画角が狭く、3頭が左端で切れていた。カメラ距離、高さ、画角をワイド用に修正した。
- 透視投影の帯で覆われないCanvas領域が黒く抜けていた。世界描画の開始時に地表色で全面を初期化した。
- 内馬場側の管理路が広すぎて巨大な茶色い面になっていたため、細い管理路と暗い内馬場へ分離した。
- ラチを一本線から上下2本の横木＋柱へ変更し、芝の大きな市松模様を弱めて進行方向の刈り筋を追加した。
- 樹林、200m間隔の汎用距離標識、照明塔をコース座標へ追加した。すべて馬と同じ透視投影を通し、画面への貼り付けは行わない。
- 樹林の初回実装は近景で巨大な円形に見えたため不採用とし、内馬場奥へ移動、画面上42px上限、3つの小樹冠へ修正した。
- 注視地点をgate / backstretch / corner / homestretchへ分類する純粋関数を追加した。直線は暗い観客席、向正面は低い設備棟、コーナーは密な樹林を選ぶ。
- 建築の初回実装は全周の別区間まで同時投影され、浮いた灰色帯になったため不採用とした。注視地点前後190mだけへ限定し、奥へ移動、低背・低コントラスト化した。

## 判定

- 固定条件におけるFraming gate（表示12頭・切れ0）は合格。
- `diag-front`はclose/finishとも専用4コマ素材で描画され、切れ0。
- 背景は黒抜け、巨大な茶色面、一本線ラチを解消し、汎用の樹林・標識・照明塔、区間別の低景まで実装した。観客の個体表現と建築ディテールは未完成のためReference gateは未合格。
- 1200〜3000m・12頭、および6頭・18頭の距離端ケースは代表フレームと全時刻連続監査に合格。展開別、左右回りは引き続き検証が必要。

## 方向別素材の進捗

- `diag-front`: 専用4コマ×8枠色シート。
- `high-diag`: 専用4コマ×8枠色シートを追加し、corner-wideでside素材を流用しないよう修正。
- `side`: 既存8コマの絵を維持し、セル単位の強アルファ連結成分解析で隣接フレーム断片9,752画素を除去した`horse-side-v3.png`へ切替済み。
- `diag-rear`: 専用4コマ×8枠色シートへ移行。発走・隊列形成・コーナー追走で尾と後躯に加えて右側面が見える。
- `rear`: 真後ろ専用の既存8コマシートを維持し、diag-rearとは共有しない。
