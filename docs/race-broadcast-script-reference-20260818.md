## 2. 特徴

- 3〜6 秒ごとにカメラが変わる TV 中継そのもの。正面・空撮・斜め前・後方・真横を使い分ける
- 真横は低いカメラで馬が大きい（画面高 35〜45%）
- 切替はカット主体、要所に閃光トランジション
- レース本編（発走〜ゴール）は 2000m を約 68 秒 → 約 1.8 倍の時間圧縮（当方の道中 1.8 倍と同等）
- 発走〜3 秒はカメラが馬群の前方にあり、馬がこちらへ向かってくる
- 勝馬は寄り・後方気味・スロー、その後に着順ボード
