# レース展開 Truth / Motion 監査

更新日: 2026-08-17

## 目的

静止画の構図監査とは別に、多数の距離・ペース・seedでレース結果と映像位置モデルの整合性、および位置の連続性を高速検査する。

実行コマンド:

```text
npm run audit:race:scenarios
```

既定条件は5距離（1200 / 1600 / 2000 / 2400 / 3000m）、3ペース、各16seed、12頭、レース時間0.1秒刻み。結果は`out/reference-audit/scenario-matrix.json`へ出力する。

## 判定内容

- エンジンの確定着順と境界時刻の順序が一致する。
- 位置モデルから二分探索したゴール順が確定着順と一致する。
- 各馬が確定走破時刻より前にゴールへ到達せず、確定時刻に到達する。
- 全時刻で前後位置が後退しない。
- 1ステップの前進量と横移動量の最大値を記録する。
- high / middle / slowを明示的な脚質構成で均等に検証する。

| 項目 | 結果 |
|---|---:|
| レース数 | 240 |
| 位置状態サンプル | 318,825 |
| high / middle / slow | 各80 |
| Truth / Motion失敗 | 0 |
| 最小前進量 | 0m |
| 0.1秒あたり最大前進量 | 1.8831m |
| 0.1秒あたり最大横移動量 | 0.1348m |

勝ち脚質は逃げ63、先行107、差し35、追込35で、すべての脚質の勝利ケースを含む。

## ゴール後表示の修正

従来の位置モデルは確定後の全馬を決勝線へ固定するため、winnerショットで全馬が一点へ集まり、距離だけでは勝ち馬を特定できなかった。

確定結果を変えず描画座標だけを延長する`withFinishRunOut()`を追加した。先着馬ほど早く決勝線を通過しているため、その時間差に応じて決勝線の先へ進む。winnerショットは確定1着馬のgateを直接参照し、横位置を含めてカメラ中央へ追従する専用カットとした。

Framing gateでは通常ショットは全馬を必須対象、winnerショットだけは確定1着馬を必須対象として判定する。

## 芝・ダート・馬場状態マトリクス

芝・ダートそれぞれで良 / 稍重 / 重 / 不良を走査した。各条件は5距離×3ペース×2seedの30レースで、全8条件合計240レース・329,674位置状態。Truth / Motion失敗は0だった。

描画側も同じsurface / trackConditionを受け取り、芝は4段階の荒れ色、ダートは4段階の土色と細かなハロー跡へ切り替える。1600m・12頭・seed 42で不良芝、良ダート、不良ダートを全編監査し、必須馬の画面外切れ0を確認した。
