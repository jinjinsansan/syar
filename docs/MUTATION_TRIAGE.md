# 変異試験の未防御21件 — §16.3 の3分類（Q-P3-40）

**作成**: 2026-08-12 / 実測: `docs/MEASURE_MUTATION_P3CLOSE.txt`（24 OK / 23 NG）

> **裁定**: 21件すべてに振る舞いテストは要らない。§16.3 の3分類では、
> **較正定数だけが振る舞いテストを要し、測定条件と正典の写しは値照合が正しい防御**。
> → 21件を分類して**較正定数だけ抜き出し、その数を報告**。

★分類の根拠は**すべてソース中のコメント**です（こちらの判断で振り分けていません）。

## 4. ★分類の作業中に見つけたこと（報告）

### `CALIBRATED_RACE_RANDOM_K` の較正条件が、いま成り立ちません

ソースにこう書いてあります:

> ⚠️ **較正条件（正典 §13.1 に明記）**: **素質開放率プレースホルダ(0.55〜0.85)**・
> クラス分け番組・18頭立て。

★**その素質開放率プレースホルダを、本便で本番経路から廃止しました**（Q-P3-35 の裁定）。
つまり **K の記録された較正条件は、もう現在の実装を指していません。**

`TAIL_MIX_*` にも同じ注記があります:

> P3 で本物の育成ループが入ったら**必ず再較正すること**（R-7）。

### ★ただし、再較正が要るとは限りません

**本番の実分布で V-4/V-5/V-6 を測り、すべて帯の中でした**:

```
V-4 32.32%（帯 30〜34%） / V-5 63.26%（帯 60〜65%） / V-6 1.00%（帯 0.5〜2%）
```

→ **ゲートは通っているので、値を動かす理由はありません。**
★動かすべきは値ではなく、**記録された較正条件のほう**です。
「0.55〜0.85 のプレースホルダの上で較正した」ではなく
「**開放率 平均71.3% / SD12.6pt の実分布の上で確認した**」に更新が要ります。

★正典 §13.1 の記述なので、**こちらでは書き換えていません**（照会 Q-P3-41）。

## 6. ★較正定数14件 — どのゲートが捕まえるか（Q-P3-40 の追加指示）

> **裁定**: 「変異試験が NG」は「防御が無い」を意味しない。
> 変異試験が回すのは**単体テスト**だが、較正定数の多くは **V-ゲートが振る舞いで守っている**。
> **防御は「速い単体テストであること」を要求していない。存在して、実行されることを要求している。**

★併せて **「ゲートの実行経路で実際に読まれているか」** も確かめました。

### ★数

```

  → **全件に対応ゲートがあり、全件が実行経路で読まれている**
```

★**したがって「本当の債務」は 0 件**です。
残るのは「**対応表を記録として残すこと**」と「**未実測の11件を実測で裏付けるか**」の判断です。

### ★未実測の11件について（正直に書きます）

上の表の「落ちるゲート」は、**登録簿の `affects` とソースのコメント**から取りました。
**実際に壊してゲートを流したのは 4件だけ**です。

- 残り11件を実測するには、V-4/V-6 系は `verify:race` を1本あたり約8分、
  V-1 系は `verify` を約8分流します（**合計およそ90分**）
- ★**「登録簿にそう書いてある」は「そのゲートが捕まえる」の証拠ではありません。**
  P1 で「クラス係数が適用経路から外れても196件が緑」を踏んだのと同じ構図です
  （あのときは経路から外れていましたが、今回は経路で読まれていることは確認済みです）

→ **実測するかどうかの判断を仰ぎます**（Q-P3-42）。こちらの見立ては
「**経路で読まれていることは確認済みなので、実測は保険。ただし4件で終わっているとは書けない**」です。
