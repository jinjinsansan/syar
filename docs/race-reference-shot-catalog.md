## 初版から確定している映像規則

1. 全編1カメラではない。
2. 引きと寄りの両方があり、馬の代表幅が大きく変わる。
3. 横、斜め前、斜め後ろ、高い俯瞰が混在する。
4. 道中は馬群全体、終盤は上位争いへ注視対象が変わる。
5. ハードカットが主体で、カメラ位置を全編連続補間していない。
6. 望遠的に奥行きを圧縮し、地面より馬群を大きく見せる。

## 次回精密化

- 元映像だけを横長で再取得できた場合、各境界を1フレーム単位で再計測する。
- 馬群矩形と代表馬幅は、SNS字幕と実況UIをマスクして測定する。
- 現時点の値はショットシーケンサーの構造を作るために使い、最終の画角値とはしない。
