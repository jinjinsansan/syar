# Claude Design 依頼プロンプト（Web 画面の基調を「明るいアーケード筐体風」へ）— 2026-08-19

背景: デザイナー側は Web 画面も中継 HUD と同じ暗色基調（放送テロップ風）で起こしたが、オーナーの目指すものは
**アーケードの競馬メダルゲーム筐体の UI**（明るい・派手・大きな数字・光沢）。暗色では「それ」に見えない。
中継 HUD（映像に重ねる部分）は合格済みなので維持し、**Web 画面（番組表／レース詳細／オッズ／牧場ホーム／馬詳細／調教／出走登録／投票／記録／景品交換）の基調だけ**を変える。

Web 画面（番組表／レース詳細／オッズ／牧場ホーム／馬詳細／調教／出走登録／投票／記録／景品交換）の**見た目の基調を変えてください**。レース中継 HUD（映像に重ねる黒い帯・金）は合格なのでそのまま。Web 画面だけが対象です。

## 目指す基調: アーケードの競馬メダルゲーム筐体の画面
- **明るい。** 地は白〜アイボリー〜明るい水色のグラデーション（暗い地は使わない）。パネルは白地に濃い縁、タイトル帯は青や赤の濃色に白抜き文字
- **派手で光沢がある。** ボタンとタイトル帯はベベル／グロス（上が明るく下が濃い 2 段グラデ）、縁は 2〜3px の濃色、角は大きめの丸み（8〜12px）
- **数字がとにかく大きい。** オッズ・EP/PP・残り時間・着順は 28〜64px の太いゴシック。色は 金／赤／青 をはっきり使い分け（例: 順位=赤、金額=金、時刻=青）
- **情報密度は高いが、罫線と帯で区画がはっきり**している（カジノ・パチスロ系の「賑やかだが読める」配置）
- 枠色 1〜8（白・黒・赤・青・黄・緑・橙・桃）は据え置き。馬番は枠色の塗り＋白縁の大きめバッジ
- 芝の緑・空の青・ゴールドを差し色に。金は「勝ち・賞金・主ボタン」に限定して使う（HUD と同じ規律）
- 文字は system-ui の太字でよい（将来、丸ゴシック系の専用書体に差し替えられるよう、フォントはトークン 1 か所に）

## やってほしいこと
1. **トークンを 2 系統に分ける**: `styles.css` に `[data-theme="arcade"]`（Web 用・明るい）を追加し、既存の暗色は HUD 用として残す。色・影・角丸・ベベルの定義を全部トークンに
2. **まず 3 枚だけ差し替え**: 番組表（program-board）・牧場ホーム（stable-home）・投票（bet-sheet）。合格後に残り 7 枚へ展開
3. 各カードの実装表も更新（地色・縁・角丸・グロスの作り方＝`linear-gradient` 2 段と `box-shadow` の値を明記）
4. 憲法はそのまま: EP と PP を合算しない／「購入・チャージ・換金・円」を使わない／実在名を使わない

まず 3 枚の見本（トークン＋番組表＋牧場ホーム＋投票）を出してください。確認後に残りへ。
