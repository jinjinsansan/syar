# レース参考映像・カメラ／スクロール実装仕様

更新日: 2026-08-17  
対象: `ダービースタリオン/ダービースタリオン2025の２D参考用.mp4`  
目的: 現在の固定背景・定点馬アニメーションを廃止し、参考映像の撮影意図を91.2秒のレース演出へ移植する。

## 1. 解析結果

参考映像の競馬画面は約296×190pxで、単一の横カメラではない。撮影文法は次の順に変化する。

1. ゲートを正面寄りから捉え、馬群が横方向へ飛び出す。
2. 低いサイドカメラが馬群を追従し、柵・距離標・背景が速度差を伴って流れる。
3. コーナー進入で正面寄りの画へ切り替え、馬群の奥行きと隊列を見せる。
4. コーナー中盤は高所俯瞰に切り替え、曲率のある柵と馬群の進行方向を見せる。
5. 直線は斜め上から追従し、先頭争いを画面中央からゴール方向へ運ぶ。

馬の位置だけでなく、カメラ、近景柵、芝、遠景、馬群の縮尺と向きを同じ区間状態から一体的に決める。背景を固定したまま馬だけを走らせる実装は禁止する。

## 3. 91.2秒レースへの割当

カット境界では同じ馬の画面座標を0.25–0.45秒補間し、瞬間移動を禁止する。

## 4. パララックス規約

画面横方向の基準速度を `v` とする。

| レイヤー | 速度 | 備考 |
|---|---:|---|
| 最前景の柵・植栽 | `-1.35v` | 画面を速く横切る。支柱間隔を均一にしすぎない |
| 手前芝模様・蹄跡 | `-1.00v` | 芝テクスチャを反復可能にする |
| 馬場内柵 | `-0.70v` | 馬群との相対運動を明瞭にする |
| 観客席・建物 | `-0.22v` | 遠景のため低速 |
| 樹木・空 | `-0.08v` | ほぼ静止だが完全固定は禁止 |

俯瞰コーナーでは横移動だけでなく、レイヤー全体に回転・斜行・縮尺変化を与える。単一画像の平行移動だけでコーナーを表現しない。

## 5. 馬群・接地表現の規約

- 全馬を同一点へ重ねず、前後差、レーン差、奥行き差を常時保持する。
- 馬の縮尺は奥行きに連動させ、前列と後列で3–12%の差を許容する。
- 発走は馬ごとに0–0.35秒の反応差を与えるが、順位エンジンの結果は変更しない。
- 脚のフレーム、上下動、前後移動を同期させず、馬ごとに位相差を与える。
- 接地影は馬体と同じ速度で追従し、脚の接地周期で濃度と幅を変える。
- 芝蹴り粒子は後肢接地時だけ発生し、速度と画角に応じて量を調整する。
- ゼッケンは馬体に追従する布として、傾き・陰影・騎手服との重なりを持たせる。

## 6. UI・実況・終了演出

- 実況は画面下部の専用枠に固定し、1〜3行を維持する。背景とのコントラスト、内側余白、細い枠線を統一する。
- カメラ切替後も実況を途切れさせない。
- コーナー名、残り距離、先頭、自馬、競り合い、ゴールの状態に応じて文面を更新する。
- ゴール後は同じ場所でループさせない。全馬を画面外方向へ進ませた後、勝馬追従へ切り替える。
- 勝者表示は `1着 N番 / 馬名 / 騎手名` を必須とし、タイム・着差は取得可能な場合に加える。

## 7. 実装順序と合格条件

1. タイトルカードを高品質画像へ置換する。
2. ゲート待機時の完全遮蔽と実況枠を修正する。
3. 発走3.3秒を単独で完成させる。
4. パララックス可能な背景レイヤー構造へ変更する。
5. 1〜4コーナーの画角を区間別に実装する。
6. 最終直線の接地影・芝蹴り・追い比べを実装する。
7. ゴール板、ランアウト、勝者表示を実装する。
8. 開発サーバーで各段階を順に目視確認する。

合格条件は静止画の美しさだけではない。再生中に「コース上を前進している」「カメラが競走を撮影している」「区間が変わった」と視聴者が迷わず認識できることを必須とする。
