## 選定の根拠

**候補探索**: 40シード（`1000 + i×7`）× 50世代

```
合格（有効系統数 ≥5 かつ 平均F ≤0.10）: 12/40（★合格率 30%）
うち4量すべてが40シード分布の中央値以上: 8件
```

★**合格率 30% を併記するのは、将来の読み手がチェリーピッキングと誤解しないため**です。
  1つの世界を選ぶのは「稀な当たりを引いた」のではなく、**3〜4シード試せば見つかる**
  水準から**余裕のあるものを選んだ**ということです。

## ★D-032 との衝突と、その解決（D-033）

当初 `1231` の平均F 0.0287 は V-12 の帯（0.03〜0.10・D-032）の下限を下回るため、
帯を満たす `1259`（F 0.0364）を推奨しました。

レビュー側の裁定により **D-032 の下限は「運用中の集団」にのみ当たる**ことが確定しました
（D-033）。理由:

- **V-12 は最初から時間発展を見るゲート**で、F は運用とともに上がる
- **開始世界の F が低いのは欠陥ではなく余裕**。0.0364 から始まる世界は
  0.0287 から始まる世界より早く 0.10 に達する
- 下限を開始世界に当てると、**余裕のある世界ほど弾かれる**逆の選別になる
- 開始世界に問うべきは水準ではなく**§6.5 が発火しているか**で、
  それは**高F配合の割合**で直接測れる（平均F は集団平均だが、近交弱勢は個々の配合で起きる）
  → `1231` は 8.5%（**12回に1回**は高F配合）で、機構は明確に作動している

★衝突の原因は正典2箇所の構造的な食い違いでした。
  D-028（系統多様性の高い世界を採る）と D-032（F の低い世界を弾く）は、
  **系統が多いほど交配相手の選択肢が増えて F は下がる**ため反対を向きます。
