# レース用アート制作順序

制定日: 2026-08-17  
品質基準: `docs/race-visual-quality-standard.md`  
基準背景: `apps/web/public/art/starting-gate-side-v1.png`

## 制作原則

- 承認済み発馬背景の手描き2D品質、光源、色密度、遠近感へ統一する。
- 動く対象は透明素材、背景は背景素材として分離する。
- 馬体と騎手を一枚へ固定し過ぎず、勝負服・ゼッケン・枠色を差し替えられる構造を保つ。
- 各方向は同じ素材の単純変形で済ませず、方向別に制作する。
- 1種類ずつ生成、透過処理、開発サーバー組み込み、ユーザー目視確認の順で進める。

### 横向き8コママスターの仕様

- 承認済み発馬背景を画風・光源・密度の参照に使用した。
- 既存`horse-side-v3.png`は横向きギャロップの姿勢順だけを参照した。
- 同一の鹿毛馬、同一の騎手、同一の馬具を8姿勢で生成した。
- マゼンタクロマキー原版から透過PNGを生成し、毛先・手綱・脚先を目視確認した。
- 実装用シートは2172×300px、1行8コマ。各コマのソース幅は271.5pxとして扱う。

### v4不採用とv5制作方針

- v4は8姿勢を一枚で同時生成したため、1姿勢当たりの情報量が不足し、承認済み背景と同等の品質に達しなかった。
- `pixel-painted`指定も輪郭と陰影を粗くする要因になったため撤回した。
- v5は1姿勢ずつ高解像度で制作し、承認された基準個体から残り7姿勢を派生する。
- v5 pose01は四肢を正確な4本へ修正し、承認済み背景上で実寸仮合成まで確認した。
- v5 pose01はユーザーから「このクオリティで合格」と明示的に承認された。
- v5 pose02は全肢を腹下へ集める収縮空中局面として制作し、四肢4本と透過輪郭を確認した。
- v5 pose02はユーザーから問題なしとの承認を得た。
- v5 pose03は前脚が接地へ伸び、後脚が腹下を通過する次の空中局面として制作した。四肢4本、個体・騎手・馬具・光源の連続性、透過後の栗毛色を確認済みで、ユーザー目視確認待ち。
- v5 pose03はユーザーから次工程へ進む承認を得た。
- v5 pose04は前脚が接地して荷重を受け始め、後肢が腹下へ集まる支持局面として制作した。四肢4本、個体・騎手・馬具・光源の連続性、透過後の栗毛色を確認済みで、ユーザー目視確認待ち。
- v5 pose04はユーザーから次工程へ進む承認を得た。
- v5 pose05は前脚への荷重が最大となり、馬体が支持脚の上を通過する局面として制作した。四肢4本、個体・騎手・馬具・光源の連続性、透過後の栗毛色と輪郭を確認済みで、ユーザー目視確認待ち。
- v5 pose05はユーザーから次工程へ進む承認を得た。
- v5 pose06は前脚が離地し、後肢が接地へ向かう切り替え局面として制作した。最初のマゼンタ原版は被写体内部にキー色が混入して透過欠損が出たため、被写体を維持して背景のみグリーンキーへ修復した。四肢4本、内部欠損の解消、色と輪郭を確認済みで、ユーザー目視確認待ち。
- v5 pose06はユーザーから次工程へ進む承認を得た。
- v5 pose07は後肢が接地・伸展して馬体を前方へ押し出し、前肢が回収される推進局面として制作した。四肢4本、内部欠損がないこと、個体・騎手・馬具・光源の連続性、透過後の色と輪郭を確認済みで、ユーザー目視確認待ち。
- v5 pose07はユーザーから次工程へ進む承認を得た。
- v5 pose08は後肢が蹴り切って完全に離地し、前肢が展開してpose01の最大伸展へ戻る直前の空中移行局面として制作した。四肢4本、全蹄離地、内部欠損がないこと、pose07→pose08→pose01の姿勢連続性、透過後の色と輪郭を確認済み。
- これにより、横向き馬＋騎手の高品質8コマ走行マスターが個別透過PNGとして一式揃った。
- 8枚の透過PNGは読み込み時に不透明領域を自動測定し、余白を除いた下端を接地基準として揃える実装にした。表示倍率は8枚中の最大不透明高を共通基準に固定し、脚を畳んだフレームだけ馬体が拡大する脈動も防ぐ。
- 真横カメラとゲート解放演出はv5個別フレームへ切り替えた。後方・斜めカメラは視点が異なるため、既存の各視点専用シートを維持する。
- 型検査、カメラ・導入演出の49テスト、開発サーバー`/race`のHTTP 200応答を確認済み。
- 目視確認で、未制作の斜め視点が旧素材へフォールバックして画風が断絶する問題を確認した。視点別v5が完成するまでは全ショットを真横へ統一し、旧馬素材を表示しない。v5向けにカメラを寄せ、発走時の横間隔と表示高、再生速度も調整した。
