# レース映像 ビジュアル品質基準

制定日: 2026-08-17  
基準画面: `apps/web/public/art/starting-gate-side-v1.png`を使用した側面発馬カット

## 1. ユーザー承認

2026-08-17の開発サーバー目視確認で、ユーザーから以下の評価を得た。

> この画像のクオリティはとてもいいです。このゲート、芝、背景、観客席、何もかもいいです。
> この画像のクオリティは最高です。このクオリティを維持してください。

この評価を、今後のレース画面における明示的な品質基準とする。

## 2. 維持する品質

- 発馬機は玩具的な線画ではなく、重量、構造、材質、可動部が伝わる産業機械として描く。
- 芝は単色面にせず、刈り跡、濃淡、接地影を持つ絵として描く。
- 背景はスタンド、樹木、複数のラチ、距離標をレイヤー化し、競馬場としての密度を保つ。
- 遠景は主役より暗く抑え、馬と発馬機が読みやすい奥行きを作る。
- 写真そのものではなく、高品質な手描き2D競馬ゲーム背景として統一する。
- 色調、輪郭密度、光源、遠近感を一つの画面内で揃える。
- 固有作品の素材やロゴを複製せず、STAR独自の意匠を維持する。

## 3. 今後統一する対象

以下を同一の画像生成ワークフローと品質基準で段階的に刷新する。

1. 馬体の方向別スプライト
2. 騎手、勝負服、ヘルメット
3. 発馬時の馬群と脚運び
4. 芝・ダートのコース背景
5. 内外ラチ、距離標、標識
6. 観客席、スタンド、樹木、照明設備
7. コーナー、向正面、直線、ゴール板
8. 天候・時間帯・馬場状態の差分

## 4. 制作ルール

- 新規ラスター素材はCodexの`imagegen`スキルを使用する。
- 背景、構造物、馬、騎手は可能な限り別レイヤー／別素材として制作する。
- 動く対象を背景へ焼き込まない。馬、騎手、扉、土煙は描画時に合成する。
- 生成画像をそのまま採用せず、カメラ方向、発馬口、走行余白、縮尺を目視確認する。
- 採用素材は必ずプロジェクト内へ保存し、アセットバージョンを更新する。
- 1カットずつ開発サーバーで確認し、ユーザー承認後に次のカットへ進む。
- 品質を下げて全体を急いで置換しない。承認済みカットを基準に段階的に置換する。

## 6. 生成仕様の要点

- 用途: 16:9の2D競馬ゲーム背景
- カメラ: 走路と同じ高さの固定側面カメラ
- 構図: 発馬機を左寄り、発馬口を右向き、右半分に走行余白
- 画風: 高品質な手描き2D、抑制された写実、明瞭なシルエット
- 質感: 風化した金属、油圧部品、ゴム車輪、刈られた芝、複層ラチ
- 禁止: 玩具的比率、平面的ベクター、正面に枠を並べる構図、ロゴ、透かし、背景への馬の焼き込み

## 7. 次の作業

最初に、承認済み背景へ馴染む横向きの馬・騎手スプライトを制作する。静止画一枚ではなく、走行アニメーションに必要な連続姿勢と枠色・勝負服差分を保てる構造を先に決める。

具体的な制作順序は`docs/race-art-production-order.md`を参照する。
