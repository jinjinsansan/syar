## 何が起きていたか

`tools/verify-prize.mjs` の後片付けが、`npc_stable_id` に **1 を決め打ち**して書き戻していました
（`535db6e`・2026-08-08 以来）。この道具は出走表の **最終枠を除く全頭**（1 回 **17 頭 前後**）を
プレイヤー所有にするので（`66e0dae`・2026-08-11 以来）、
**流すたびに 17 頭が、いろいろな厩舎から 厩舎 1 へ 一方向に移って**いました。

`horses_owner_xor_npc` があるため、`owner_id` を入れた時点で `npc_stable_id` は行から消えます。
この道具は**元の値を読んでさえいなかった**ので、**殺されなくても、正常終了のたびに失っていました。**
