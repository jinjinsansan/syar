## 🔴 なぜ取り消すか — **`baseScore` は勝敗を決めていません**

続けて測ったら、こうでした（本番 6,075 レース）:

```
★1番人気 ＝ baseScore 最強  : 31.6%     ← ★3 回に 1 回しか一致しない
★1番人気の勝率              : 22.57%
★baseScore 最強の勝率       : 17.17%    ← ★1番人気より低い
```

**MC が選ぶ 1 番人気のほうが、`baseScore` 最強の馬より 5.4pp よく勝ちます。**
→ **`baseScore` は、着順を決めている量の一部にすぎません。**
　距離適性・馬場・脚質・枠・年齢・斤量・道悪・スキル・レーンが、残りを決めています。

→ 🔴 **したがって、私が測った「散らばり 7.23%」は`baseScore` の散らばりであって、
　　実際に着順を決める量の散らばりではありません。**
→ **「散らばりは同じなのに勝率が違う」から「散らばりは犯人ではない」は、導けません。**
　比べるべきは **全係数を掛けた後のスコア**の散らばりです。**まだ測っていません。**

⚠️ レビュー側の「クラスが犯人ではない」（クラス間 0.74%）は、この訂正の影響を受けません
（あれは平均能力の話で、`baseScore` でも同じ結論になります）。
