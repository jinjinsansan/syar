## 🔴 予言（向き）

**V-4 は B のほうが低くなる。**

## 機序（★私の読み。★レビュー側の当初の説とは別）

レビュー側は当初「創始の乱数が序列に雑音を載せる」と言い、**自分で取り下げました** —
オッズも同じ `stats` を見るので、雑音を共有しているなら 1 番人気は当たり続けるからです。**その取り下げは正しい。**

私が効くと思うのは **雑音ではなく、散らばりの幅** です。

`unlockRate` は **馬ごとに 1 回**引かれ、5 能力すべてに同じ倍率で掛かります。

| | 比（max/min） | 平均のまわりの相対幅 |
|---|---|---|
| 0.55〜0.85 | 1.55 | 約 ±21% |
| 0.28〜0.35 | **1.25** | 約 **±11%** |

スコアは完全に乗法（`race.ts:229-241`）なので、**全馬を同じ倍率で縮めても着順は動きません**。
動くのは **馬どうしの散らばりが `RACE_RANDOM_K` の荒れに対してどれだけ広いか** です。

- 幅が広い → 能力差が乱数に勝つ → **1 番人気が勝つ**
- 幅が狭い → 乱数が能力差に勝つ → **1 番人気が勝たない**

B は幅が **狭い** ので、V-4 は下がるはず。

## 🔴 どちらに転んでも言えないこと（★**AB-1**）

**この 1 本では因果は言えません。** 言えるのは **合成の中の A と B の比較**までです。

- B が **22% 付近に落ちた** → 「育っていないこと」で **説明が付く**（★本番がそうだとは言えない）
- B が **32% 付近のまま** → 🔴 **原因は別に在る。★本番に、まだ知らない何かがある**

⚠️ 本番と合成の間には **DB・世界の作り方・クラス編成・3 日分の履歴** が挟まったままです。
この実験はそれを 1 つも潰しません。**潰すのは「素質開放率だけで説明が付くか」の 1 点だけ**です。

# 予言 4（2026-09-20・★4 つの量を測る**前**に記録）

## まず、分解が**厳密**であることを確かめました

`baseScore` は **重み付き和**です（`coefficients.ts:57-60`）。
素質開放率 `u` は**馬ごとに 1 回**引かれ、**5 能力すべてに同じ倍率**で掛かります。

→ したがって **`baseScore(potential × u) = u × baseScore(potential)`** が**厳密に**成り立ちます。

独立なら:
```
CV(base(stats))² = CV(u)² + CV(base(pot))² + CV(u)²·CV(base(pot))²
                 ≒ CV(u)² + CV(base(pot))²        （交差項は小さい）
```

## 🔴 ただし、レビュー側の予言 4 には**取り違えが 1 つ**あります

分解は **CV を計算した集合の中**でしか成り立ちません。
測った **7.23% は「レース内」** の CV です。だから解けるのは:

> **レース内**の `CV(base(potential))` ≒ √(7.23² − 6.4²) ＝ **約 3.4%**

**「集団全体」の CV ではありません。**
クラス分けと出走馬の選び方が、レース内の散らばりを**狭めている**はずなので、
**集団全体の CV(potential) は 3.4% より大きい**はずです。

## 予言

| # | 量 | 予言 |
|---|---|---|
| 4a | 本番の**レース内** `CV(base(potential))` | **3〜4%**（分解どおり） |
| 4b | 本番の**集団全体** `CV(base(potential))` | 🔴 **4a より大きい**（クラス分けのぶん） |
| 4c | 本番の**レース内** `CV(base(stats))` | 7.23%（測定済み・確認用） |
| 4d | 合成 A / B の**集団全体** `CV(base(potential))` | **本番より大きい** |

⚠️ **4b が 4a と同じだったら**、クラス分けは散らばりを**狭めていません**
（＝ レースの組み方が実力で選んでいない）。それはそれで答えです。

⚠️ 🔴 **根拠は上の近似分解だけです。弱いです。**
特に「`u` と `potential` が独立」は**確かめていません**。
`seed-world.mjs` が両方を同じ乱数列から引いていれば、相関しているかもしれません。

> **オッズは同じ出走表を `resolveRace` で回して作ります。**
> → **オッズは `condition` を「見て」います。**

```

本番  condition が全頭 3       → その信号がゼロ → 1 番人気が勝ちにくい
```

→ **これは「差を大きくする交絡」ではありません。「差を説明する候補」です。**
→ **潰れていません。いまの本命です。**

⚠️ 私は同じ便の ④ と ⑤ で**逆のことを書いていました**。⑤ のほうが正しい。
