# 予言 — 合成で「育っていない馬」を回すとどうなるか（2026-09-20・★数が出る前に書く）

> ⚠️ **後から書くと、どんな結果にも説明が付いてしまいます。**
> これは **数を見る前** に書いたものです。

## 何を変えるか

合成のハーネスは `stats = potential × 素質開放率` で馬を作ります。

| 腕 | `--unlock-min` / `--unlock-max` | 何のつもりか |
|---|---|---|
| **A（対照）** | 0.55 / 0.85（既定のプレースホルダ） | いまの較正が立っている条件 |
| **B（処置）** | **0.28 / 0.35** | **本番の馬**（創始のまま育っていない・`phenotype.ts:84`） |

- `--pool` は **使いません**（プール file は staging の育った馬の `stats` をそのまま使うため）。
- `K` は **0.22**（本番が走った値。★交絡を作らない）。
- 8 シード（VP-4′）。

## 🔴 予言（向き）

**V-4 は B のほうが低くなる。**

## 機序（★私の読み。★レビュー側の当初の説とは別）

レビュー側は当初「創始の乱数が序列に雑音を載せる」と言い、**自分で取り下げました** —
オッズも同じ `stats` を見るので、雑音を共有しているなら 1 番人気は当たり続けるからです。**その取り下げは正しい。**

私が効くと思うのは **雑音ではなく、散らばりの幅** です。

`unlockRate` は **馬ごとに 1 回**引かれ、5 能力すべてに同じ倍率で掛かります。

| | 比（max/min） | 平均のまわりの相対幅 |
|---|---|---|
| 0.55〜0.85 | 1.55 | 約 ±21% |
| 0.28〜0.35 | **1.25** | 約 **±11%** |

スコアは完全に乗法（`race.ts:229-241`）なので、**全馬を同じ倍率で縮めても着順は動きません**。
動くのは **馬どうしの散らばりが `RACE_RANDOM_K` の荒れに対してどれだけ広いか** です。

- 幅が広い → 能力差が乱数に勝つ → **1 番人気が勝つ**
- 幅が狭い → 乱数が能力差に勝つ → **1 番人気が勝たない**

B は幅が **狭い** ので、V-4 は下がるはず。

## 🔴 どちらに転んでも言えないこと（★**AB-1**）

**この 1 本では因果は言えません。** 言えるのは **合成の中の A と B の比較**までです。

- B が **22% 付近に落ちた** → 「育っていないこと」で **説明が付く**（★本番がそうだとは言えない）
- B が **32% 付近のまま** → 🔴 **原因は別に在る。★本番に、まだ知らない何かがある**

⚠️ 本番と合成の間には **DB・世界の作り方・クラス編成・3 日分の履歴** が挟まったままです。
この実験はそれを 1 つも潰しません。**潰すのは「素質開放率だけで説明が付くか」の 1 点だけ**です。
