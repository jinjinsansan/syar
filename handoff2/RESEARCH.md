# 調べたこと — 中央競馬の中継

★**私は映像を見られません。** 以下は**公開されている記述**からの再構成です。
★**出典があるもの**と**★推測**を分けて書きます。**推測を事実として使わないでください。**

---

## 1. 発走の手順 ★出典あり

**これは画面の設計にそのまま使えます。順序が明確に決まっています。**

| # | 起きること | 出典 |
|---|---|---|
| 1 | 出走馬はゲート後方で**輪乗り**をしている | JRA 初心者向け解説（BIGLOBE 競馬）、note「競馬のおはなし ④1レースの流れ」 |
| 2 | 発走時刻になると**発走委員（スターター）が台に上がる**。昇降式のトラックの荷台に乗って上昇する | note「競馬のおはなし ④」 |
| 3 | ★**スターターが赤い旗を振る → ファンファーレが鳴る** | Wikipedia「ファンファーレ (競馬)」、ニコニコ大百科 |
| 4 | ファンファーレを合図に**ゲートインを開始**する | BIGLOBE 競馬、note |
| 5 | ★**枠入りの順序**: 枠入りに難のある馬を先に入れる → 奇数番 → 偶数番 → **大外は最後** | BIGLOBE 競馬、blog「枠入れの順序と外枠発走について」 |
| 6 | ★**全馬が入ると、間髪いれずにゲートが開く** | BIGLOBE 競馬 |

★**ファンファーレは「旗を振る」という視覚の合図と同時に始まります。** 音が無くても、
**旗が振られた瞬間に画面が変わる**なら「始まった」と伝わります。
→ `scenes/gate-fanfare.png` はこれを絵にしたものです。

★**日本の競馬に特徴的な形式**とされています（他国ではファンファーレが無い場合が多い）。
「業界共通の作法」として採ってよい範囲です（§2-1）。

### ★注意（推測しなかったこと）
**「ファンファーレから何秒でゲートが開くか」は、公開情報から特定できませんでした。**
枠入りにかかる時間は頭数と馬の気性で大きく変わり（１頭が暴れれば数分かかる）、
**固定の秒数が存在しません。** → 秒数を決めるなら**実装側の演出の都合**で決めてください。
下の `cuts.md` では **★推測**として 3.0 秒を置いています。

## 2. 中継の構成 ★一部出典あり

- 中継には**中継車（OB van）**が使われ、**ITV（実況用映像）とパトロールビデオ**が扱われます — 出典: 中継技術の一般的な解説
- ★**「GI で約20台」はそちらの調査値**です。**私は裏を取れませんでした。** そのまま採るか、要確認としてください
- ★**カメラの切り替え位置**（スタンドのメイン → 向正面は併走車 → 各コーナー → 直線・ゴール前）も
  そちらの調査値です。★**ただし `camera.ts` のカット表はこの構成と矛盾しません**ので、
  設計としてはこのまま進めて問題ないと考えます

## 3. 距離と差 ★出典あり — ★これは数値で使えます

| 単位 | 距離 | 出典 |
|---|---|---|
| **1馬身** | **約 2.4m**（伸びきった姿勢での鼻端〜臀端。馬格により 240〜250cm） | 競馬ブック用語辞典、dbpedia「着差 (競馬)」 |
| ハナ差 | 約 20cm | dbpedia「着差 (競馬)」 |
| アタマ差 | 約 40cm | 同上 |
| クビ差 | 約 80cm | 同上 |
| **1秒** | **約 5〜6馬身**（日本では 6馬身 = 14.4m として計算） | Wikipedia「着差 (競馬)」、Umas! |
| 大差 | 11馬身以上はすべて「大差」 | Wikipedia「着差 (競馬)」 |
| 端数 | **4馬身以上は端数を数えない**（「6馬身とクビ差」は存在しない） | Wikipedia「着差 (競馬)」 |

★**着順表の着差ラベルは、この規則どおりに出してください。** 4馬身以上で「1 1/4」のような
端数を出すと、競馬を見ている人には**すぐに間違いと分かります。**

★**これは画面の縮尺にも使えます。** 第1便の `zoom 20px/m` では **1馬身 = 48px**。
220×140 のスプライトは 1× で 220px 幅 ≒ **4.6馬身**。
→ ★**スプライトは実寸より 4.6倍 大きい**ことになります。
   ⚠️ **これは直すべきではありません。** 実寸にすると馬が小さすぎて何も見えません。
   ただし「差 1.8m」という表示と、画面上の見た目の差が**一致しません**。
   → **差の表示は画面の見た目と切り離して扱ってください**（数字は正しく、絵は誇張）。

## 4. 隊列 ★そちらの調査値を採用

- 道中は 10馬身くらいで一団 = **24m** に 12〜18頭
- 通過順位が `8-8-8-4` のように**前3つが同じ**＝**道中は動かない**

★**これは画面設計に直結します。** 24m を `zoom 14px/m`（向正面のカット）で見ると **336px**。
1280px の画面に対して**馬群は画面の 26%** にしかなりません。
→ ⚠️ **第1便の構図（馬群が画面いっぱい）は、実寸では成立していません。**
   ★**それでよい**と考えます。中継の望遠レンズは馬間を圧縮して見せるので、
   `camera.ts` の `xCompression 0.85` はまさにその再現です。**構図は変えないでください**（§6-2）。

## 5. ★推測（出典なし。設計の都合で置いた数字）

**以下は「調べた結果」ではありません。** 1600m・馬速 17m/s（1600m を 94秒）から**逆算**しました。

| 局面 | 残り距離 | ★推測の経過秒 | 根拠 |
|---|---|---|---|
| 発走 | 1600m | 0.0s | — |
| 隊列形成 | 1400m | 11.8s | 200m ÷ 17m/s |
| 向正面 | コースが決める | ★`course.ts` から読む | ⚠️ 秒で書かないこと（§camera.ts の失敗） |
| 3角 | 同上 | 同上 | 同上 |
| 4角 | 同上 | 同上 | 同上 |
| 直線 | 同上 | 同上 | 同上 |
| 追い比べ | 200m | 82.4s | (1600−200) ÷ 17 |
| ゴール | 0m | 94.1s | — |

★**区間の秒数を書き写さないでください。** `camera.ts` のコメントに
「区間の境目はコースが知っています。書き写さず、読みます」「2度目です」とある失敗を、
**私が同じ表で繰り返すわけにはいきません。**
→ `cuts.md` では**残り距離だけ**を持ち、秒は「切り替わってからの経過」にのみ使います。

## 6. ★調べたが分からなかったこと

- **ゴール後に何を何秒映すか** — 公開情報から特定できませんでした
- **カメラの正確な台数と設置位置** — 同上
- **直線で画面に何頭入るか** — 望遠のレンズ選択と競馬場ごとの距離で変わるため、一般化できません

★これらは**⑤⑥（最終直線・ゴール）と一緒に第3便で**扱わせてください。
**推測で埋めると、いちばん大事な場面が根拠のない数字で固まります。**
